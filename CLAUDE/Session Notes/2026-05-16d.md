## What Was Done

### Phase D1 — MapCursor input gating (behavior change, in place)
- `MapCursor._handle_key_press` — direction keys now branch on `_state`:
  `FREE`/`UNIT_SELECTED` move the cursor freely (with held-key auto-repeat);
  `TARGETING`/`STAFF_TARGETING` cycle between valid targets via the new `_cycle_target`;
  `UNIT_MOVED`/`PREVIEWING` ignore direction keys.
- `MapCursor._process` — clears `_held_dir` if the state left free movement, so a held
  arrow can't drift the cursor after confirming into a menu/targeting context.
- `MapCursor._handle_mouse_motion` — branches on `_state`: free move in `FREE`/
  `UNIT_SELECTED`; `_handle_targeting_mouse_motion` in targeting modes; ignored in
  `UNIT_MOVED`/`PREVIEWING`.
- `_handle_targeting_mouse_motion` reads the `SettingsManager.mouse_targeting` setting:
  `"snap"` snaps the cursor to the Manhattan-nearest valid target tile; `"disabled"`
  ignores motion (clicks still confirm/cancel).
- No automated test for D1 — input gating can't be driven headlessly (the core D-1
  motivation). Verified by reasoning + the D2 test net.

### Phase D2 — Extract MapCursorTargeting (refactor + input re-point)
- New `scripts/core/MapCursorTargeting.gd` — `RefCounted`, dependency-injected
  (`grid`/`attack_preview`/`combat_resolver` via `setup()`). Owns the attack/staff
  targeting flow: `begin()`, `handle_confirm()`, `handle_cancel()`, `target_tiles()`,
  `can_change_target()`, `is_active()`; signals `completed`/`cancelled`. Internal
  `_Sub` enum (IDLE/CHOOSING/PREVIEWING) replaces the old cursor states.
- `MapCursor.State` collapsed from 7 to 5: `FREE, UNIT_SELECTED, UNIT_MOVED, TARGETING,
  LOCKED` (`PREVIEWING`/`STAFF_TARGETING` removed). Removed `_attack_tiles`/`_heal_tiles`/
  `_preview_target` and the seven extracted methods; `MapCursor` now delegates while in
  `TARGETING` and reacts to `_on_targeting_completed`/`_on_targeting_cancelled`. The D1
  input layer was re-pointed at `_targeting.target_tiles()` / `can_change_target()`.
- New `scripts/tests/test_targeting.gd` (13 tests) — drives `MapCursorTargeting` against a
  live `GameMap`: no-target/in-range attack discovery, confirm-with-null-preview resolve,
  cancel from CHOOSING, the CHOOSING→PREVIEWING→resolve path (via a `StubPreview` node),
  and staff healing. Added to `run_tests.sh`.

## Gotcha — global class cache
`MapCursorTargeting.gd` was created outside the Godot editor, so its `class_name` was not
in `.godot/global_script_class_cache.cfg` (which is gitignored). Headless `--script` runs
could not resolve the type until the entry was added to that cache by hand. The editor
will regenerate it normally; the manual entry just keeps local headless tests green. Saved
as an auto-memory.
