### GDD conflict fixes — commit `d4e77d0`

#### Range formulas (WeaponData)
- Removed `range_min: int` and `range_max: int` from `WeaponData.gd`
- Replaced with `range_min_formula: String` and `range_max_formula: String`
- Added `get_range_min(unit)` / `get_range_max(unit)` methods with a static formula evaluator
- Supported syntax: integer literals (`"1"`, `"2"`), stat/divisor (`"MAG/2"`)
- All 6 weapon `.tres` files updated to new field names (same effective values for static weapons)
- `GridManager._get_weapon_range()` and `CombatResolver.can_counterattack()` updated to use methods
- Dynamic staves like Physic can now be authored with `range_max_formula = "MAG/2"` — no further code changes needed

#### Brave weapons (CombatResolver)
- `resolve_combat()` now reads `strikes_per_attack` from both weapons before building the sequence
- Attacker with `strikes_per_attack = 2` fires twice before the defender counters
- `preview_combat()` also updated to reflect correct attack counts

#### Aura skills (CombatResolver)
- Added `_apply_aura_bonuses(attacker, defender, context)` — scans all living units for `trigger = "aura"` skills
- Added `_apply_one_aura()` — handles `charm` (+10 hit/dodge for allies within 3), `anathema` (-10 hit/dodge for enemies within 3), `daunt` (-10 hit/crit for enemies within 3)
- Bonuses stored as `attacker_aura_hit`, `attacker_aura_dodge`, `defender_aura_*` etc. in the main context
- `_resolve_one_attack()` merges these into per-exchange skill bonuses, including the dodge→accuracy conversion
- Called at the start of every `resolve_combat()` after `on_combat_start` skills

#### Faire / Breaker (SkillHandler)
- Added `faire` passive handler: +N damage when attacking with matching weapon type (reads `opponent_weapon` passed through bonuses context)
- Added `breaker` passive handler: +N hit when opponent wields matching weapon type
- Note: Breaker's dodge side (+50 dodge vs that weapon type when defending) is **deferred** — implementing it requires modifying `compute_hit_pct`'s signature to accept a separate defender-dodge context
- `_get_skill_bonuses()` now passes `opponent_weapon` in the bonuses dict

#### Laguz deferred
- Added `# [DEFERRED — Laguz]` comment to `Unit.has_quality()` explaining that Beast/Laguz qualities must check `is_shifted` before returning true — will incorrectly fire in humanoid form until Laguz mechanics are implemented
- All Laguz content (Taguel, Manakete, Beaststone/Dragonstone weapons, Beastbane/Dragonskin/Stoneborn/Wyrmsbane skills) is deferred

#### Naming convention
- Added comment in `GameConstants.gd` documenting the convention to prevent future weapon/skill ID collisions (Luna style): weapon ids that would clash with skill effect_ids should use `_tome` suffix

#### Supplement document fix
- Removed duplicate Rightful King entry from `awakening_skills_supplement.md`
- Added clarifying note about why skills appear in both Generic and Class-Specific sections
