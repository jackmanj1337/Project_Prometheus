### Implementation Plan — `CLAUDE/Docs/implementation_plan_2026-05-16.md`
Six phases: A correctness fixes, B `-1` infinite-use sentinel, C settings split + New Game

### D2 Design — `CLAUDE/Docs/d2_mapcursortargeting_design.md`
Design for extracting `MapCursorTargeting`: a `RefCounted` with dependency injection; the cursor
FSM stays on `MapCursor`; `TARGETING`/`PREVIEWING`/`STAFF_TARGETING` collapse to one state plus
internal sub-state; communication via `begin()`/`handle_confirm()`/`handle_cancel()` and
`completed`/`cancelled` signals.

### Decisions Locked
- Gameplay rules (`permadeath`, `leveling_method`) become per-save state set on a New Game
  screen; audio/video/keybindings stay global in `settings.cfg`.
- `-1` = infinite-use sentinel for `InventoryEntry`. MVP keeps finite durability everywhere
  except the lance + vulnerary on `unit_01_soldier.tres` (deliberate test case).
- Mouse behavior in targeting is a player setting (`mouse_targeting`: `snap`/`disabled`);
  `disabled` affects cursor motion only — clicks still confirm/cancel.
- New Game screen is an overlay child of `MainMenu` (matches `SettingsScreen` pattern).
- D2 object type: `RefCounted` with DI; cursor FSM ownership stays on `MapCursor`.
