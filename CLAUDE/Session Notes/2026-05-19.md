The user asked to (1) merge the deferred features into the to-do list, (2) write

## What Was Done

### 1. Planning

- **Merged the 8 deferred features** into a new `### UI / UX & Settings`
  subsection of `GDD_10_Roadmap.md`'s Phase 3 Backlog.
- **Wrote the fix plan** — `CLAUDE/Docs/playtest2_fix_plan_2026-05-19.md`:
  per-item severity, `file:line`, root cause, recommended fix, tradeoffs, plus a
  prioritized action plan. One High (#5 dead mouse input); the rest Medium/Low.

- **Pre-Release Cleanup** section added to `GDD_10_Roadmap.md` flagging the #10/#11
  debug aids as a RELEASE BLOCKER to delete before shipping.

### 2. All 17 findings implemented (one commit each, suite green per commit)

- **#5** — HUD root `Control` had the default `MOUSE_FILTER_STOP` and swallowed
  every mouse event; set the HUD + panels to `MOUSE_FILTER_IGNORE`.
- **#14 / #13** — Vulnerary heals 10 (was 20); LevelUpScreen prompt shows the
  real confirm key. New `scripts/shared/InputDisplay.gd` helper (preload-only).
- **#9** — `_on_targeting_cancelled` snaps the cursor back to the acting unit.
- **#4** — New Game screen gained an opaque Dimmer + panel StyleBox.
- **#3** — `prev_unit` (Shift+Tab) is now decoded (`PREV_UNIT` intent) and wired
  to reverse cycling; the keybind list renders modifiers via `InputDisplay`.
- **#12** — level-up screen freezes the cursor via a new `_input_suppressed`
  flag driven by `EventBus.level_up_started/finished` (independent of the FSM
  `_state`, which `_finish_action` resets to FREE mid-combat).
- **#2 / #17** — `SettingsManager.auto_end_turn` + `camera_edge_buffer`, with
  SettingsScreen rows; `TurnManager` gates auto-end; `MapCursor` reads the buffer
  per-scroll.
- **#6** — heal overlay recoloured green → orange; `OVERLAY_GREEN` renamed
  `OVERLAY_HEAL`. Colour is provisional ("try orange").
- **#15 / #16** — end-turn confirm dialog focuses the Cancel button so a mashed
  confirm can't end the turn early.
- **#7** — `EnemyAI` emits `EventBus.ai_unit_acting`; `GameMap` pans the camera
  and enables position smoothing for the enemy phase.
- **#8** — weapon swap: new `WeaponMenu` + ActionMenu "Equip" option;
  `Unit.set_equipped_weapon` reorders the inventory (order = equip state).
- **#1** — read-only `UnitDetailsScreen`, opened by the new `inspect_unit` (I)
  action; reuses `_input_suppressed` so a live selection survives inspection.
- **#10 / #11** — debug testing aids, gated on `OS.is_debug_build()`:
  `GameState.debug_force_levelup` (100 EXP per hit) and `debug_growth_boost`
  (+50 to growth rates). **Must be removed before release.**
