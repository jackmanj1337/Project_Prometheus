### 2. M16 stage 2 — generic per-group evaluator (commit `badeec6`)

`check_victory_conditions` rewritten as a generic evaluator. Loops every
alliance group with at least one registered faction OR an authored
condition set, ANDs that group's victory conditions, ORs its defeat
conditions, falls back to the implicit "group routed" default for groups
without authored defeat conditions, then applies the last-standing / draw
rules.

Legacy translation: `objective_type == "rout"` → blue victory
`rout(faction_id="")`; `turn_limit > 0` → blue defeat `turn_limit(turns=...)`;
`required_survivor_ids` → blue defeat `protect(unit_ids=...)`. Treats them
as implicit blue-group conditions so every existing map and test reads
identically.

New state:
- `_group_eliminated_round: Dictionary` — group → turn_number eliminated.
  Reset implicitly per-map (new TurnManager instance).
- `get_group_eliminated_round(group) -> int` — accessor for stage 4
  standings.

Internal `_group_routed` sentinel keeps `rout(faction_id="")` meaning
"all hostiles wiped" rather than overloading it with "this group is wiped".
Stage 2's blue-perspective signals (`map_victory` / `map_defeat`) stay
exactly as before for the existing GameOverScreen; the ranked-standings
UI reads `_group_eliminated_round` directly in stage 4.

test_turn_manager +5: per-group victory, per-group defeat, last-standing,
draw, get_group_eliminated_round.

### 3. M16 stage 3 — defeat_boss / seize / escape / survive (commit `bd2d12e`)

Adds the four remaining condition types from the catalogue plus the
runtime event tracking and UI wiring they need.

`TurnManager`:
- `_seize_records: Array<{tile, unit_id, faction}>` — populated by
  `record_seize(unit)`; the cursor calls this when the player commits the
  Seize action.
- `_escape_records: Array<{unit_id, faction}>` — populated by
  `record_escape(unit)`, which unregisters the unit from GameState and
  queue_frees it (escape ≠ death).
- `can_seize(unit, tile) -> bool` — the ActionMenu gate (Decision 4).
- `_on_unit_moved` bus hook — auto-escape on zone entry (Decision 5).
- `_eval_seize` / `_eval_escape` / `_eval_survive` / `_eval_all_named_dead`
  (the defeat_boss helper) added to the `_evaluate_condition` match arm.

Subtle bit: a group whose only members have escaped must NOT be marked
"routed" by the implicit-default defeat. Escape records carry faction
info so `_group_has_no_living_units` can spare a group with any escapee,
and `_eval_protect_failed` treats escaped ids as still-alive (the spec
ties protect-failure to "death" specifically).

`ActionMenu` / `MapCursor`:
- `ActionMenu.tscn`: + BtnSeize between Equip and Wait.
- `ActionMenu.show_for(unit, grid, turn = null)` — `turn` is the
  TurnManager; Seize stays hidden when null. Button visibility reads
  `turn.can_seize(unit, unit.tile_position)`.
- `MapCursor`: passes `_turn` into `action_menu.show_for`; handles
  `"seize"` action via `_commit_seize` → record + `_finish_action`.

test_action_menu +3 (Seize visibility), one assertion bumped (Wait now
index 5 in `_buttons`).
test_turn_manager +7 (defeat_boss, survive, record_seize victory,
can_seize gate, record_escape victory, escape exclusion in protect,
unit_moved auto-escape).

### 4. M16 stage 4 — ranked-standings + HUD readout (commit `8fed076`)

`EventBus.map_resolved(winner_group: String, standings: Array)` — emitted
alongside `map_victory` / `map_defeat`. Standings entries are dicts
`{group, eliminated_round, rank, is_blue_group}`. Winner gets rank 1;
losers sort by elimination round DESC (stable). Draw emits `winner=""`
and the losers start at rank 1.

- `TurnManager._build_standings` constructs the array; emitted from both
  the winner-decided and draw branches of `check_victory_conditions`.
- `ObjectiveCondition.get_display_text()` — per-type one-liners for the
  HUD ("Rout %s", "Defeat %s", "Seize %s", "Survive %d turn(s)", …).
- `GameOverScreen.tscn` + `Standings` Label between Title and Retry;
  `GameOverScreen.gd` listens to `map_resolved` and paints the formatted
  standings ("1. Allies (you)", "2. Foes — eliminated turn 3", "Draw" in
  the top slot when there's no winner).
- `HUD.tscn` + ObjectivePanel (header + list Label) top-left; `HUD.gd`
  populates it from the active MapData on `setup`. "Win:" / "Lose:"
  grouped readout; each header only appears when at least one matching
  entry follows.

test_data_layer +1 (per-type display text), test_hud +2 (objective
lines, empty MapData), test_turn_manager +2 (blue-victory standings,
draw standings).

### 5. M16 stage 5 — Decision 7 plumbing + legacy retirement (this commit)

Two halves:

**Decision 7 plumbing.** The hybrid trigger model from the design log:
- **Phase-boundary sweep** now fires at `start_enemy_phase` too — not
  just `start_player_phase`. A win/loss decided during the prior phase
  by something other than `unit_died` / `unit_moved` is caught here.
- **`_map_over` chokepoint at the controller.** `EnemyAI.run_enemy_phase`
  checks `turn._map_over` between units and bails (and bails again
  before the trailing `start_player_phase`). A decided map no longer
  plays out remaining AI activations.
- Event-driven evaluation (death, seize, escape) was already in place
  from stages 2-3. Round-counter conditions read `turn_number`, which
  ticks once per round (M14 stage 3 ALTERNATING / `end_player_phase`
  for WHOLE_PHASE — both correct).

**Legacy retirement.** The legacy MapData fields are deleted:
- `MapData`: `objective_type` / `objective_params` / `turn_limit` /
  `required_survivor_ids` removed. Only the new per-group dicts remain.
- `TurnManager`: `_apply_legacy_conditions` / `_has_legacy_blue_conditions`
  deleted; `_all_evaluated_groups` no longer needs the blue-fallback clause.
- `HUD._build_objective_lines`: legacy-translation branches deleted.
- `map_001_data.tres`: migrated to
  `victory_conditions = {"allies": [rout()]}` via a sub-resource block.
  No `defeat_conditions` — the implicit "group routed" default supplies
  the all-allies-dead defeat.
- `test_turn_manager` + `test_hud` + `test_data_layer`: every legacy
  field reference rewritten to authored conditions (preserved coverage
  rather than deleting tests).

test_turn_manager +1 (phase-boundary sweep on start_enemy_phase fires
map_defeat + sets _map_over).
