**Commit: Implement Amendment A3**

Complete A3 refactor of `CombatResolver.gd` and `SkillHandler.gd`:

**New/changed in CombatResolver:**
- `_build_combat_context()`: structured `atk_mod`/`def_mod`/`flags` dicts with zero defaults
- `_collect_combat_modifiers()`: 4-step pipeline — UnitData active_modifiers → atk/def_mod; aura skills via SkillHandler `on_combat_apply_modifiers`; equip items; `on_combat_start` triggers
- `_get_effectiveness_multiplier()`: respects `skip_effectiveness` flag; Giantkiller = 4×, standard effective = 3×
- `_resolve_single_attack()`: fires `on_attack`/`on_hit`/`on_damaged`/`on_kill` triggers; handles `damage_multiplier`; passes `target_sim_hp` to Miracle
- `_skill_available()` / `_consume_skill()`: per-map use limit helpers
- `resolve_combat()` and `preview_combat()` both use the context pipeline
- `compute_hit_pct`: added `dodge_bonus` context key for defender dodge modifiers
- `compute_damage`: added `effectiveness_mult` and `ignore_def_fraction` context keys; backward-compat when called without context
- `apply_combat_result`: increments `data.damage_taken_this_map` per hit
- Removed old `_get_skill_bonuses`, `_apply_aura_bonuses`, `_apply_one_aura`

**Updated in SkillHandler:**
- `resolve`/`wrath`: write to `atk_mod`/`def_mod` (no longer flat context keys)
- `vantage`: sets `context["flags"]["vantage"] = true` (defender only)
- `faire`/`breaker`/`stat_bonus`: write to `atk_mod`/`def_mod` based on role
- Added `charm`/`anathema`/`daunt` implementations for `on_combat_apply_modifiers`

**Skill .tres updates:**
- `resolve.tres`, `wrath.tres`: trigger changed from `"passive"` → `"on_combat_start"`
