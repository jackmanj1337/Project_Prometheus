## Known Issues / Decisions Made
1. **`DataManager.get_class_data()`** — renamed from `get_class()` to avoid conflict with
   Godot's built-in `Object.get_class() -> String`. All future code should call
   `DataManager.get_class_data(id)` not `get_class(id)`.

2. **TILE_SIZE = 64** — GDD_01 says 32px, GDD_06 says 64px. Using 64 to match the
   tileset spec and checklist sprite sizes. GDD_01's "40×22 visible tiles" is based
   on the old 32px assumption; at 64px you see ~20×11 tiles.

3. **Audio buses** — `default_bus_layout.tres` is a placeholder. The Music and SFX
   buses must be added by opening the project in the Godot editor and adding them
   in the Audio panel. Until then, SettingsManager will print errors on startup.

4. **.tres type format** — All .tres files use `type="Resource"` (not `type="ClassData"` etc.)
   because custom GDScript class names are not resolvable in `--script` headless mode.
   This is correct behavior and works fine — the `script = ExtResource(...)` property
   assigns the actual type. The Godot editor will update these to the proper type names
   when opened.
