# Session Notes — 2026-05-16 (Session G)

End: 11 suites, 247 tests green.

## What Was Done

### #1 High — Nihil ordering bug (symmetric negation)
A defending Nihil bearer couldn't negate the attacker, because the attacker's
`on_combat_start` skills applied before the defender's Nihil ran. Added an
`on_combat_start_negate` pre-pass in `CombatResolver._collect_combat_modifiers` that
resolves the `*_skills_blocked` flags before any modifier skill runs; both
`on_combat_start` passes are now guarded by the final flags. Retagged `nihil.tres` to
the new trigger. `_apply_nihil` itself was already symmetric and unchanged. Added a
defender-Nihil regression test + a no-Nihil control to `test_combat`.

### #2 Medium — weapon durability moved into the simulation
`resolve_combat` simulated every strike with infinite uses and let
`apply_combat_result` discard broken-weapon exchanges — so skill triggers fired during
simulation for attacks the apply phase threw away. Added `_equipped_weapon_uses()` and
`_resolve_strike()`: `resolve_combat` now tracks per-unit weapon uses and stops a
unit's strike series the moment its weapon breaks. `apply_combat_result` lost its skip
logic — every exchange it receives is now a real attack. `MockUnit.get_equipped_weapon_entry`
updated to mirror `_weapon_uses`; mid-combat-break test now also asserts the exchange
count (1, not 4).

### #3 — enemy start_of_turn skills
`TurnManager.start_enemy_phase` now calls `_apply_start_of_turn_skills` for enemy units,
symmetric with `start_player_phase`.

### #4 Medium — staff-gate consolidation
`ActionMenu.show_for` and `EnemyAI._try_staff_heal` switched from
`weapon_type == "staff"` to `is_healing_staff()`; added the `_equipped_can_attack`
guard to `GridManager.can_attack_from_tile`.

### #5 Low — polish batch
HUD clears its info panel on `unit_died`; `preview_combat` exposes `defender_vantage`
and `AttackPreview` tags the defender name `[Vantage]`; stale `attacker_skills_blocked
(unused)` schema comment corrected (done with #1); `Unit._increment_stat` marked
`NOT ENFORCED` for per-class stat caps.

### Follow-up — Nihil exemption list
User asked, while Nihil was open, for a list of skills Nihil can't negate. Added
`SkillHandler.NIHIL_EXEMPT_SKILLS` (matched by skill id). `apply_trigger` gained a
`skills_blocked` flag — when set, only exempt skills fire — and `CombatResolver` now
passes the per-side blocked flag through instead of skipping the whole trigger. Seeded
with `s_rank_mastery` and `nihil` (user's choice). Regression test added: S-Rank
Mastery applies while Swordfaire is negated on the same Nihil-blocked unit.
