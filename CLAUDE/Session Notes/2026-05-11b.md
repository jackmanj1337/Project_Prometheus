### M5 implementation (all in one commit)

#### EnemyAI (`scripts/core/EnemyAI.gd`) — new autoload
- `run_enemy_phase(grid, turn)`: iterates living enemies, awaits each `_act`, then calls
  `turn.start_player_phase()`.
- `_act(enemy, grid, turn)`: find nearest player → get movement range → `_choose_move_tile`
  → move (await animation) → attack if in range → mark DONE.
- `_choose_move_tile`: prefers tiles from which enemy can attack; falls back to closest tile
  to nearest player when no attack possible.
- `_find_nearest`: Manhattan distance scan, returns closest valid unit.

#### TurnManager (`scripts/core/TurnManager.gd`)
- `start_enemy_phase()` now awaits `EnemyAI.run_enemy_phase()`; falls back to
  `call_deferred("start_player_phase")` if EnemyAI autoload is absent (headless tests).

#### MapCursor (`scripts/core/MapCursor.gd`)
- New `@export var item_menu: Node` export.
- `_ready()` now connects to `EventBus.phase_changed` → `_on_phase_changed`: locks cursor
  during enemy phase (phase=1), unlocks on player phase (phase=0).
- `_use_item()` shows ItemMenu when wired; falls back to auto-consume if not.
- Added `_on_item_chosen(entry)`, `_on_item_menu_cancelled()`, `_apply_item_effect(entry)`.

#### LevelUpScreen (`scripts/ui/LevelUpScreen.gd` + `scenes/ui/LevelUpScreen.tscn`)
- Listens to `EventBus.unit_leveled_up`; only shows for player units (enemy level-ups silent).
- Queues multiple level-ups; shows one at a time; player presses A to advance.
- Blocks all input while visible via `_unhandled_input` + `set_input_as_handled`.
- Placed in `LevelUpLayer` (CanvasLayer, layer=10) inside GameMap.tscn.

#### ItemMenu (`scripts/ui/ItemMenu.gd` + `scenes/ui/ItemMenu.tscn`)
- Dynamically builds one Button per usable inventory item (type=item, uses_remaining>0).
- Emits `item_chosen(entry)` or `cancelled`.
- Placed in HUDLayer alongside ActionMenu; wired to MapCursor via NodePath export.

#### CombatHUD (`scripts/ui/CombatHUD.gd`)
- CanvasLayer (layer=5) placed in GameMap.tscn.
- Listens to `EventBus.combat_resolved` → spawns floating labels (damage, "CRIT! N", "Miss")
  above units; tweens upward + fades over 0.8 s.
- Listens to `EventBus.unit_healed` → spawns green "+N" labels.
