### Part 3 — Implement all fixes
All 17 issues addressed and all 71 tests passing before push.

#### BUG fixes
- **BUG-01** `MapCursor`: mouse-to-tile now uses `canvas_transform.affine_inverse()`, not the
  camera node's global transform. Fixes tile selection after the camera scrolls.
- **BUG-02** `MapCursor`: `get_unit_at()` result stored in a local variable, not called twice.
- **BUG-03** Tests: `GameConstants.TILE_SIZE` used instead of literal `64`.
- **BUG-04** `Unit.move_along_path`: `_original_tile` promoted from class field to local variable.
- **BUG-05** `Unit.initialize`: dead `is_inside_tree()` guard removed.
- **BUG-06** `MapCursor`: cursor now rests in `"unit_moved"` after movement. A second confirm
  triggers Wait (DONE), cancel triggers undo-move back to `"unit_selected"`.
  `_commit_wait()` and `_undo_move_and_reselect()` added.

#### DESIGN fixes
- **DESIGN-01** `SettingsManager`: audio bus volume set by name (`get_bus_index`), not index.
- **DESIGN-02** `Unit._get_class_data()` / `_load_weapon()`: direct-load fallbacks removed;
  both return `null` if DataManager is unavailable.
- **DESIGN-03** Map grid moved from `GameMap.MAP_001` const to `MapData.grid` field. `GameMap`
  now loads `map_data` first, then derives width/height from the grid.
- **DESIGN-04** `Unit.add_exp()`: returns early at `GameConstants.MAX_LEVEL = 20`; zeroes EXP overflow.
- **DESIGN-05** `GameState.register_unit()`: duplicate-registration guard with `push_error`.
- **DESIGN-06** `UnitData.str` → `strength` everywhere (14 .tres files, GDScript code, snapshot keys).

#### GDD fixes
- **GDD-01** `TurnManager._apply_fort_healing()`: heals units on fort tiles by 10% max HP at the
  start of both player and enemy phases. `start_map()` now accepts a `GridManager` parameter.
- **GDD-02** `Unit.level_up()`: `push_warning` if `GameState.leveling_method != "growth_rates"`.
- **GDD-03** `map_001_data.tres`: `tilemap_scene_path` cleared; `grid` field populated with the
  26-row map string array.
- **GDD-04** `GDD_06_Maps_Objectives.md`: E7 corrected from "Sub-boss on Fort" to
  "Standard enemy on Fort; is_boss=false". Spot-check label updated in `test_map_grid.gd`.
- **GDD-05** `GameConstants.gd`: `TAG_EFFECTIVE_FLYING`, `TAG_EFFECTIVE_ARMOURED`,
  `TAG_EFFECTIVE_MOUNTED`, `TAG_EFFECTIVE_DRAGON`, `TAG_EFFECTIVE_BEAST`, `TAG_HEAL_PLUS_MAG`
