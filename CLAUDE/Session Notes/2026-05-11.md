#### BUG fixes
- **BUG-01** `MapCursor`: mouse-to-tile now uses `canvas_transform.affine_inverse()`, not the
  camera node's global transform. Fixes tile selection after the camera scrolls.
- **BUG-02** `MapCursor`: `get_unit_at()` result stored in a local variable, not called twice.
- **BUG-03** Tests: `GameConstants.TILE_SIZE` used instead of literal `64`.
- **BUG-04** `Unit.move_along_path`: `_original_tile` promoted from class field to local variable.
- **BUG-05** `Unit.initialize`: dead `is_inside_tree()` guard removed.
- **BUG-06** `MapCursor`: cursor now rests in `"unit_moved"` after movement. A second confirm
  triggers Wait (DONE), cancel triggers undo-move back to `"unit_selected"`.
  `_commit_wait()` and `_undo_move_and_reselect()` added.

#### DESIGN fixes
- **DESIGN-01** `SettingsManager`: audio bus volume set by name (`get_bus_index`), not index.
- **DESIGN-02** `Unit._get_class_data()` / `_load_weapon()`: direct-load fallbacks removed;
  both return `null` if DataManager is unavailable.
- **DESIGN-03** Map grid moved from `GameMap.MAP_001` const to `MapData.grid` field. `GameMap`
  now loads `map_data` first, then derives width/height from the grid.
- **DESIGN-04** `Unit.add_exp()`: returns early at `GameConstants.MAX_LEVEL = 20`; zeroes EXP overflow.
- **DESIGN-05** `GameState.register_unit()`: duplicate-registration guard with `push_error`.
- **DESIGN-06** `UnitData.str` → `strength` everywhere (14 .tres files, GDScript code, snapshot keys).

#### GDD fixes
- **GDD-01** `TurnManager._apply_fort_healing()`: heals units on fort tiles by 10% max HP at the
  start of both player and enemy phases. `start_map()` now accepts a `GridManager` parameter.
- **GDD-02** `Unit.level_up()`: `push_warning` if `GameState.leveling_method != "growth_rates"`.
- **GDD-03** `map_001_data.tres`: `tilemap_scene_path` cleared; `grid` field populated with the
  26-row map string array.

## M4 — Combat / Action Menu (completed this session)

### CombatResolver (`scripts/core/CombatResolver.gd`)
- Autoload at `/root/CombatResolver`
- Stateless math engine: `compute_hit_pct`, `compute_damage`, `compute_crit_pct`
- Weapon triangle embedded as `_WEAPON_TRIANGLE` const (avoids DataManager dependency in headless tests)
- Effective weapons: triple Mt on tag match
- `preview_combat` — pure preview dict, no RNG
- `resolve_combat` — full RNG sequence (vantage, follow-up, Miracle support)
- `apply_combat_result` — applies HP, durability, wEXP, EXP, death; emits EventBus signals
- **Key GDScript lesson**: `:=` can't infer type from ternary-null → must use `var w: WeaponData = ...`

### SkillHandler (`scripts/skills/SkillHandler.gd`)
- Autoload at `/root/SkillHandler`
- `apply_trigger(unit, trigger, context)` dispatches to per-skill handlers
- Skills: Renewal (start_of_turn heal 10%), Vantage (go first), Nihil (block opponent skills),
  Resolve (+dmg/acc at ≤50% HP), Wrath (+50 crit at ≤50% HP), Miracle (LUK% survive fatal), stat_bonus

### ActionMenu (`scripts/ui/ActionMenu.gd` + `scenes/ui/ActionMenu.tscn`)
- 4 buttons: Attack / Staff / Item / Wait; each disabled when not applicable
- Keyboard navigation (up/down) and cancel handled via `_input`
- Signals: `action_chosen(action)`, `hidden_by_cancel`

### MapCursor (`scripts/core/MapCursor.gd`) — extended state machine
New states:
- `targeting` — cursor on enemy tiles; confirm → CombatResolver.resolve_combat → apply
- `staff_targeting` — cursor on ally tiles; confirm → heal (10 + mag), wEXP, EXP
- Cancel from targeting/staff_targeting returns to `unit_moved` (ActionMenu re-shown)
- `action_menu: Node` export (typed Node, not ActionMenu, to compile in headless test mode)
- Without ActionMenu wired, falls back to `_commit_wait()` immediately after move

### TurnManager (`scripts/core/TurnManager.gd`)
- Added `_apply_start_of_turn_skills()` called at start of player phase → fires Renewal

### test_combat.gd
- 19 tests, all passing: hit/damage/crit, weapon triangle, effective weapons, range,
  follow-up, EXP table, damage floor, preview keys
