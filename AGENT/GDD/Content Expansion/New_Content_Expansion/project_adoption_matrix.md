# Project Adoption Matrix

This directory is an external Fire Emblem Awakening reference corpus. It is not
the live Project Prometheus design contract. A corpus rule becomes authoritative
only after a dated decision adopts it and the numbered GDD is updated.

| Reference mechanic | Project status |
|---|---|
| Five equipped skills | Adopted as the current default; future campaigns may override |
| Follow-up at +5 Battle Speed | Adopted as the current default; future campaigns may override |
| Class weapon-rank caps | Current classes author A as the default cap; explicit S caps remain possible |
| Flying movement categories | Planned; must be implemented through terrain movement-cost categories |
| Pair Up stat bonuses/actions | Pass 1 implemented |
| Dual Strike / Dual Guard / adjacent support | Planned or omitted until separately adopted |
| Tactical AI scoring | Deferred to a separate AI task |

For authority ordering, see `AGENT/GDD/GDD_00_Overview.md`.
