## Decisions `[STY-13..15]` + `[STY-12]` RESOLVED
- **STY-13** Staves fold in via a first-class source **`effect_kind`** (`strike|heal|teleport|fetch|
  repair|cure|inflict|bolster`) + **`target_filter`** (`enemy|ally|self|empty_tile|weapon_holder`).
  "Use a source" is the one pipeline; **Attack = `strike` + hostile**. Most staves = source + null style.
  Disambiguated **Rescue *staff*** (`fetch`, teleport-adjacent) vs **Rescue *carry*** (#6/H3, A2);
  Hammerne = `repair`/`weapon_holder` (the `[CEX-19]` repair path); Restore = `cure`.
- **STY-14** (designer refinement) `effect_kind`/`target_filter` are the source **default** but a
  **style may OVERRIDE them** → one source can expose **both aggressive AND beneficial** styles. Status
  payloads (`inflict`/`bolster`) ride F5. **`sleep` is shared by capture (`[STY-6]`) and the Sleep staff.**
- **STY-5 refinement** a style's cost may **OVERRIDE** the base source cost (not just add) —
  `cost = { override_source_cost, components }`. Default = additive.
- **STY-15** menu = **Attack** (strike/hostile) + **Staff/Use** (utility) as two entries over the ONE
  pipeline (extends `[CEX-21]`; no separate pipeline).
- **STY-12 RESOLVED → build the FULL F5 `ConditionManager` now**, pulled onto **A1's critical path**.
  Capture `sleep` + style status + buff/debuff staves all need it; do the full system, not just `sleep`.
