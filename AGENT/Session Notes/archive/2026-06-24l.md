## Decision `[STY-16]` RESOLVED
A committed **source+style combo carries a SET of effects**, resolved together on one use (designer
refinement). Also corrects `[STY-13]`'s single-`effect_kind` framing — and matches the existing
`WeaponData.effect_tags: Array[String]` (whose comment already anticipates `poison_on_hit`).
- Each effect = an **`EffectSpec`** = `{ kind, payload, target_filter (per-effect), gate
  (always|on_hit|on_kill) }`. `gate` reuses the F11 combat context.
- Combo effect set = **source effects ∪ style effects** (`[STY-14]`: a style may **add or override**).
  Resolve in listed order, each gated.
- **Examples:** poison dagger = `strike` + `inflict:poison`(on_hit); legendary staff = `heal` +
  `bolster` + `cure`; **Nosferatu/Sol** = `strike`(enemy) + `heal:self`(=dmg, on_hit) — **per-effect
  target differs within one use**.
- **Implications:** combined-preview (`[STY-10]`) must show **all** effects; cost (`[STY-5]`) stays
  per-*combo* not per-effect; `inflict`/`bolster`/`cure` route through full **F5** (`[STY-12]`); reuses
  `effect_tags` as the storage seam (extended with payload+target+gate).
