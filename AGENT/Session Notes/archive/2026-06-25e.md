## 2. Code-grounded substrate found
**Pair-Up already solves "two units, one tile":** `PairUpRegistry` stores `unit_id -> {partner_id,
role}` and parks the support unit at the **`OFF_MAP_TILE (-1,-1)`** sentinel while paired; snapshotted
with `GameState._map_start_snapshot` for Retry. `GridManager.get_unit_at` is the single occupancy
lookup; pathfinding respects occupants. **Carry = the same shape** → DSP mirrors this, no new occupancy
model. Rescue/carry/`grant_extra_turn` are NOT built (grep clean); Pair-Up IS.
