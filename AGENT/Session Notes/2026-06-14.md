### Investigation (full diagnosis delivered to the user)
Root-caused all 6 defects + 3 observations against the code. Notably: Defect 3
(pair-up bonuses) turned out to be a **correct code path** end-to-end (table →
resolver → `add_modifier("combat")` → `get_effective_stat` → `compute_damage`),

flagged for live re-test after the other fixes + a visible-indicator UX follow-up.

### Fixes — five defects, each its own commit with a regression test + docs DoD
1. **`iron_axe` unknown weapon (#1, `c69347b`)** — no axe `WeaponData` existed but
   four Fighter units referenced `iron_axe`; `DataManager.get_weapon` push_error'd
   11,829×/pass. Added `data/weapons/iron_axe.tres` + manifest entry. New durable
   guard `test_unit_inventory_refs.gd` scans every UnitData under `data/maps` +
   `data/roster` for dangling weapon/item refs.
2. **Pair Up Swap no-op (#2, `4924dde`)** — `swap_roles()` only flipped registry
   role labels; `MapCursor._commit_swap_roles` never moved the units. Now mirrors
   `_on_pair_up_resolved` (new lead → on-map tile + visible, old lead → OFF_MAP_TILE
   + hidden). Strengthened the swap test to assert positions/visibility.
3. **Allied-Rout never ends + AI (1,1) beeline (#4, `8c2ff81`)** — two coupled bugs:
   (A) `TurnManager._eval_rout` used `get_living_units_of` (excludes paired supports)
   → added `GameState.get_all_living_units_of` (true liveness) and use it; (B) added
   an `OFF_MAP_TILE` backstop in `EnemyAI._living_hostiles_for_faction` so a desynced
   off-map unit can't drag enemies to the top-left corner. Guards in
   `test_turn_manager.gd` + `test_enemy_ai.gd`.
4. **New Game settings not persisted (#1.2, `2080b29`)** — rules committed only on
   Start. Added `NewGameScreen._persist_rules`, wired to each toggle's `item_selected`
   (Start now shares it). Map/roster stay Start-only. Guard in `test_new_game_screen.gd`.
5. **Promotion modal off-screen (#5 = 8.7/8.11, `e7afb51`)** — left-pinned fixed-offset
   panel + long unwrapped stat rows. Centered via anchors with symmetric grow +
   `autowrap_mode` on option buttons. Guard in `test_promotion_screen.gd` (asserts
   on-screen + centered). Headless geometry only — a real-build visual confirm is
   still worth doing.
