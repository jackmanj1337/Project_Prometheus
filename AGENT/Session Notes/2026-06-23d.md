## 2. Resolutions
- **[DMR-1] = A** — unify error channels: one `_validate_all() -> Array[String]` folds the
  `skill.validate()` loop + `collect_validation_errors` + `collect_map_registry_validation_errors`,
  push_errored by a single `_report()` sink. `skill.validate()`'s bool return kept for its other callers.
- **[DMR-2] = A** — load-phase errors (missing dir, dup id) stay surfaced **inline** at the I/O site
  (`_load_directory` + `LoadResult`); only cross-reference *validation* feeds the unified channel. Two
  failure classes kept distinct. (An overlay-load failure is the same *load*-class fault → inline too.)
- **[DMR-3] = A** — add a `_validate_all()` **composition** test (good fixtures → `[]`; one broken
  fixture per validator category → its message) + a [DMR-4] **seam** test (`_load_all(base, null)` =
  byte-identical boot; `_apply_overlay()` stub reached, resolution unchanged).
- **[DMR-4] NEW = A** — **parameterize the campaign base+overlay load seam now, defer merge semantics
  to I3.** Build deltas over the pure refactor: (1) `_load_all(base_source, overlay_source := null)`
  (null default = identical boot, behavior-preserving); (2) new public `select_campaign(campaign)` =
  `_load_all(DEFAULTS, campaign.content_dir)` + id-cache re-resolve (present but **uncalled** until
  §2 campaign-select / I3 wire it); (3) `_apply_overlay()` ships as a documented **no-op stub** that
  pushes a loud error if handed a non-empty overlay (premature caller fails loud, not silent).
  **Forward dep:** `campaign.content_dir`/overlay-source shape is an I3 + §2 `CampaignData` field —
  DMR only assumes "a source the loader can enumerate," not its format.
