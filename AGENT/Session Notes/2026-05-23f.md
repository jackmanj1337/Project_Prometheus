## Decisions worth remembering
- **`OFF_MAP_TILE = Vector2i(-1, -1)`** is the sentinel for off-map
  support units (Q2: lead-only on map). Defined as a const on
  `PairUpRegistry` so step 6c, step 9, and step 11 (Charm aura helper)
  all reference the same value.
- **Bonus resolver chose a hybrid model**: per-class flat block from
  `data/pair_up/pair_up_bonus_table.tres`, plus universal scaling
  `floor(support_stat / scaling_divisor)`. Unknown support classes
  still get scaling (every unit can support; the table just specializes
  flavor per class).
- **Bonuses applied as `duration_type="combat"` modifiers** rather than
  a hand-rolled combat-stat translation. Existing `get_effective_stat`
  damage/accuracy/dodge readers pick them up automatically.
- **Per-turn `pair_up_action_this_turn` flag deferred** — Q8 listed it
  as a reload-exploit protection, but it has no observable effect until
  a save system exists. Will land before the save-system milestone.
- **`MapCursorTargeting.Mode.PAIR_UP` reuses the heal overlay** for
  visual target highlighting — same "pick a friendly" affordance as
  staff targeting, no new overlay color needed.
