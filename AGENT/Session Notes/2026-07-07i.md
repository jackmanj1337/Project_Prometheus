# Session Note 2026-07-07i - B6-INPUT key-rebind pass implemented

## What was done

Built the `B6-INPUT` key-rebind pass from the 2026-07-07h handoff on
`v0.3.0-features`.

1. **Persistence foundation.** `SettingsManager` now stores keybinding overrides as
   profile-ready `active_profile` / `profiles` data under `[controls]`. The active
   `"Default"` profile maps `action -> {"kbd": token, "pad": token}`. Tokens are
   human-readable (`Y`, `Shift+Tab`, `Mouse1`, `JoyA`, `JoyButtonN`, `JoyAxisN+/-`),
   old `Object(InputEvent...)` cfg blobs migrate into the new shape, bad hand-edited
   tokens fall back to the action's default slot, and `rebind_action` preserves the
   other device slot. Added batch `apply_keybindings(pending)`.

2. **Staged keyboard/mouse UI.** `SettingsScreen` rows now stage keyboard/mouse captures
   in a pending buffer without touching live bindings. Same-slot conflicts mark both rows
   red and disable Apply; Clear can vacate a slot; Revert discards pending edits; Reset
   Controls remains available. Debug-only rows stay read-only.

3. **Gamepad capture.** The same staged UI now captures joypad buttons and axes into the
   `pad` slot with textual labels. Pad conflicts are scoped to pad slots, and Apply commits
   through `SettingsManager.apply_keybindings`.

Updated DoD docs in `GDD_01`, `GDD_07`, `GDD_10`, `GDD_Feature_Index`, and the Project
Control Plane. No generated docs/index update was needed.
