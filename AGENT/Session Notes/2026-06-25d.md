## 2. The Source + Style model — new register `[STY-1..17]`
**attack = `source` + optional `style`.** Source = `[CEX-20]` weapon/spell/natural/battalion-gambit;
style = a modifier layer; plain attack = null style. One pipeline:
select source → select style → combined preview → re-derived targeting → pay combo cost → resolve.
- **STY-1** unify (absorbs CEX-23) · **STY-2** `StyleDef` resource via `player_activated` · **STY-3**
  binding `(learned ∩ weapon-type gate) ∪ weapon-granted` (+ wielder requirements; **cap → A5**) ·
  **STY-4** modifies stat+range+AoE now, **status → F5** · **STY-5** composable multi-resource cost
  (combo = source + style cost set; a style may **override** the base source cost) · **STY-6** capture =
  non-lethal style (can't drop below 1 HP; would-be-kill → **`sleep`**; carry → A2) · **STY-7** full 3H
  battalions, but A1 slice = gambit-as-style only (**entity → A2, STY-11**) · **STY-8** a style **is**
  the attack/one action (**counters carry NO style** — always source + null style; edge-cases → A2).
- **STY-9** AoE/multi-target vocab: `single/multi(N)/blast(R)/line/cone/cross/`**`rectangle(W,L,anchor_
  side)`**`/all_matching`; origin self/tile/unit + direction (4-way v1); per-effect `target_filter` over
  the footprint (one `strike+heal` blast damages enemies AND heals allies); **friendly fire = a broad
  target_filter** (enemy-only default); no LoS v1.
- **STY-10** combined preview: **one generalized "effect forecast" panel** (1v1 strike = today's two-box
  `AttackPreview` back-compat; utility = single-sided; **AoE = footprint + focused-target cycle**); lists
  every effect with its gate + total combo cost.
- **STY-13** staves fold in via a source **`effects` set** (generalizes `effect_tags`) +
  **`target_filter`** · **STY-14** a source may expose aggressive AND beneficial styles; a style may
  add/override effects · **STY-15** menu = Attack + Staff/Use over one pipeline · **STY-16** a combo
  carries **multiple effects** (`EffectSpec{kind,payload,target_filter,gate}`; poison dagger, Nosferatu,
  legendary staff).
- **STY-17** the **faction relationship matrix** ("aggression matrix"): upgrade `are_hostile`
  (binary/symmetric) → an author-defined **directed 3-state** `relationship(from,to)∈{hostile|neutral|
  allied}`; default from alliance groups; consumed by targeting + AI/EXP/objectives; **provoked
  transitions → A4** (MET action + AI provoke).
