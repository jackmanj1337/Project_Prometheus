## 1. Why re-OPEN (not "just defer to build")
The architecture pass (`[BAT-1..13]`) defined *how* a battalion attaches and confers, but deliberately
left *what* it confers, *what it runs on*, and *what happens to it across the unit lifecycle*. Two of
these (`[BAT-15]` endurance, `[BAT-16]` destruction/host-death) are **persistent-state** decisions — so
they **must** be settled in the define-all sweep **before the F1 lock**, not hand-waved at build. Marking
them OPEN puts them in the sweep instead of losing them inside "the battalion build."

## 2. The three new OPEN items
- **`[BAT-14]` Bonus content & shape** (refines `[BAT-3]`'s pipeline-only resolution): which stat axes a
  bonus touches (7 stats / derived Hit-Avo-Crit / future Charm-Command F14 `[STM]`), conditional vs
  always-on (lean = **always-on flat block**), rank scaling (lean = **per-rank authored table**).
  Data-def, not engine — but the *axes* depend on F14 if Charm/Command are targets.
- **`[BAT-15]` Resource model** (firms the `[BAT-5]` lean): **one-pool vs two-pool** — lean = **two named
  resources**: `charges` (per-map gambit budget via the `[AGT §5]` rate-limit primitive) + `endurance`
  (a persistent attrition meter that drives destruction). What drains endurance (gambit / host combat /
  HP loss) and replenishment (per-map refill vs prep-hub/`[SHP]` repair) — lean = **charges refill per
  map; endurance only recovers via an authored repair action**. Save: persistent `endurance`+rank,
  transient `charges`.
- **`[BAT-16]` Lifecycle — destruction & host-death** (the genuine gap):
  - **Destruction:** endurance-zero = `disband` (destroyed) **vs** `exhausted` (survives, no use until
    repaired — the softer default), a `CampaignRules` choice.
  - **Host death:** default = the battalion **detaches → unassigned pool** for reassignment (it's an
    authored asset, like an item back to convoy); harsh override `lost_with_host`.
  - **Reconcile:** route host-death disposition through the **single `handle_death` hook** the **A5
    death-inventory disposition rule set** (pinned 2026-06-25h) already mandates — a sibling case to
    dropped/convoyed inventory + the `[DSP-5]` "death while carrying" precedent. **No second death hook.**
