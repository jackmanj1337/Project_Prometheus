## What was done

**`S4`, the `NMTE-1..20` owner walk, ran — and re-scoped the packet instead of resolving it.**
The precedence diff's §7 put the scope question first on the grounds that it was cheap and
would set the detail level for everything after it. It ended the walk instead.

**`[NMTE-S1]` — non-modal text entry is editor-only.** It stays out of the core gameplay loops
and is reserved for the campaign editor, where the author can be told that a mouse, a physical
keyboard and a large screen are strongly recommended (`[NMTE-S2]`). No game screen — compendium,
shop, convoy, prep, library — gets an inline live filter in v1. Game-side text entry is
unchanged and stays modal, exactly as `TEXT-01..15` ratified it.

**`[NMTE-S3]` — game-UI discovery is the closed candidate list over pack content**, per the
2026-08-06 enumerable-vocabulary ruling: one pack is active at a time, so its units, classes and
items are all known, and "a filtered candidate list beats a keyboard outright". **`TEXT-15`'s
revisit trigger does not fire** — it was conditioned on `EPUX-15`'s free-text search being
*restored*, and it is not. "No prediction now" and the keypad presenter's "do not build" stand,
unspent.

**`[NMTE-S4]` — the residue walks with `CEUI` (`S11`), not before it.** Walking it first would
decide editor behaviour without the editor in the room, which is the inverted-dependency shape
this project has now hit six times.

**Also ruled, and it is what made the rest coherent: `[CEUI-5]`, the editor viewport floor.**
The owner rejected all three options (1280×720 / 1024×768 / full Compact) in favour of **a
maximized-browser floor of `1920×880`** — 1920 wide, just under 1080 tall after browser chrome
and taskbar, using a pessimistic ~200px allowance. **The editor is now Expanded-only with one
responsive state.** `B`'s one-side-panel compact desktop mode does not exist, so `CEUI-1`'s
composition never collapses and the editor has no Medium and no Compact behaviour to design.
Cost accepted deliberately: 1366×768 laptops and non-maximized windows get the minimum-size
state, not a working editor.

**The modality collision was dissolved, not arbitrated.** `S3` found that the Compact design
ratified 2026-08-06 says *"a text session is modal"* while `NMTE-3`/`9`/`12` were written as
though modality were open at every size class, and framed the choice as
size-class-conditional-versus-amend. The owner removed the collision instead by removing the
Compact consumer. **The Compact ruling stands unamended.** A precedence diff that surfaces a
collision is doing its job even when the answer is neither option it framed.

**Disposition of the twenty: six closed outright, three narrowed, twelve moved to `CEUI`.**
Beyond `S3`'s three precedence closures (`NMTE-4`/`10`/`16`), the scope ruling closes `NMTE-3`
(size-class-conditional modality is not needed), `NMTE-9` as a game-UI question, **`NMTE-11`
entirely** (no native keyboard exists and the editor assumes a physical one, so the
available-content-rect signal the diff had preserved is not needed either) and **`NMTE-12`**
(no in-game keyboard is visible in the editor; the game session is modal). `NMTE-17`'s
announcement half was **withdrawn rather than promoted** — with no non-modal game surface, the
project does not need to invent a shell-wide screen-reader announcement contract yet.

Three of the twelve survivors are narrowed and must not be walked as written: `NMTE-14` becomes
a keyboard question rather than a controller one, `NMTE-13` shrinks to "the window crosses the
floor mid-edit" now that the editor has one size class, and `NMTE-6` (IME) gets *more*
important, because a physical-keyboard-first surface is where platform IME actually appears.

**The cost of the ruling was measured, not assumed.** `grep LineEdit scenes/ scripts/ui/`
returns only the text-entry subsystem itself, and there is no `search`, `filter_text` or `query`
anywhere in `scripts/ui/`. No built surface loses anything, and every designed consumer was
already cut (`EPUX-15`), backlogged (`IMPL-REFERENCE-COMPENDIUM` at `5-backlog`) or held
