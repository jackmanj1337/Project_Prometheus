## 1. Discussion → decisions (owner-stated)
- **Render scale model:** `TILE_SIZE` (world grid) stays 64; introduce `SPRITE_SOURCE_SIZE` distinct
  from it, render scale = `TILE_SIZE / SPRITE_SOURCE_SIZE`. Decouples art fidelity from the grid; a
  later art-tier change is a constant flip, no gameplay-code churn. (Correcting an earlier mistake of
  mine: the project art is uniformly **64px** today — the "32" only lived in the importer *tutorial*;
  so `frame_size = TILE_SIZE` was never actually wrong for the existing art.)
- **First release = 32px** FE-style art (units + terrain, **uniform, no mixing**) scaled **2×** to the
  64-unit grid → integer scale, *more* pixel-perfect zoom levels (the 2× base pre-multiplies). **Later
  tier = 64px** (1× scale) for more class-variant detail — a wholesale constant flip, not per-asset.
- **Release license = MIT + Commons Clause** (source-available, no-sell).

## 2. Asset-licensing analysis (the core of the session)
- **Project license ≠ asset license** — MIT+CC covers original work; third-party art keeps its own
  license; need a per-asset manifest.
- **Source-available repo = redistribution of every committed file.** So "no-redistribute" paid packs
  are fine *inside exported builds* but **not** committable to public source.
- **Whitelist (public-repo + maybe-sell-later):** **CC0 > OGA-BY/CC-BY**; avoid NC (forecloses
  monetization), CC-BY-SA/GPL copyleft (ShareAlike + Steam/iOS DRM-clause), and no-redistribute packs.
- **FE fan art / rips:** dev placeholder only — never in public source; no project license cures the
  Nintendo IP. **Commission with full copyright assignment = cleanest** for a source-available project
  (owned → license freely, covers fliers/mounts no pack has).
- **Resolution-tier interaction:** the best public-repo-safe breadth source — **LPC CC0/OGA-BY subset
  — is ~64px**, so it fits the **later 64px tier**; the **32px first release** falls back to fragmented
  CC0 OGA sets + a commission. (Source scan: HEROES 99 = 32px GBA-FE modular, great license, **but
  overworld 4-dir sprites still in development**; PIPOYA 32×32 4-dir but no-redistribute → build-only.)
