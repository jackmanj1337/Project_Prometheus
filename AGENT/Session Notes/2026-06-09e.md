## What was done

### W6a — Map details show one-based tile coordinates

- Added a new `TerrainCoord` Label to `scenes/ui/HUD.tscn`, sitting between
  `TerrainName` and `TerrainDef` in the TerrainInfoPanel VBox. Uses the same
  muted grey modulate as the existing hint line so it reads as secondary
  info.
- `HUD._update_terrain` now sets `_terrain_coord.text` to
  `"Tile (%d, %d)" % [tile.x + 1, tile.y + 1]`. Internal `Vector2i`
  storage stays zero-based; the `+1` lives only at the display site.
- Regression in `test_hud.gd`: tile `(0, 0)` renders as `Tile (1, 1)` and
  tile `(7, 4)` renders as `Tile (8, 5)`.

### W6f — Movement Cancel returns cursor to the selected unit

- `MapCursor._undo_move_and_reselect` now snaps the cursor onto
  `_selection.selected_unit.tile_position` after the slice's undo +
  overlay recompute. Previously the cursor was left on the cancelled
  destination, away from the unit still holding the action.
- Mirrors the same `_set_tile(selected_unit.tile_position)` call that
  `_on_targeting_cancelled` already performs (#9 fix), so both cancel
  paths converge on the same UX.
- Regression in `test_map_cursor.gd`: park the cursor on a far tile, call
  `_undo_move_and_reselect`, assert `current_tile == mover.tile_position`.

### W6e — Mouse-wheel over the New Game UI does not move the camera

- `scenes/ui/NewGameScreen.tscn` root `Control`, `Dimmer`, and `Panel`
  all carry an explicit `mouse_filter = 0` (STOP). Default Control
  filter is STOP, but writing it explicitly guards against a future
  scene edit silently flipping it to PASS and leaking wheel events
  through to whatever camera sits underneath the title screen.

### W6i — New Game options panel is centered under its title

- The `Panel` PanelContainer was anchored to fixed offsets (440 → 840 px
  at 1280-wide), which only happened to look centered at the default
  viewport and drifted at any other width.
- Re-anchored using `anchors_preset = 8` (center): `anchor_left = 0.5`,
  `anchor_top = 0.5`, `anchor_right = 0.5`, `anchor_bottom = 0.5`, with
  symmetric offsets (`offset_left = -200`, `offset_right = 200`,
  `offset_top = -145`, `offset_bottom = 145`) and `grow_horizontal /
  grow_vertical = 2`. The panel now centers itself horizontally and
  vertically regardless of viewport size.
