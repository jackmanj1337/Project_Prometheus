  no `iron_axe` for war_monk to wield. The level-15 case rides on
  `unit_08_sniper` (starts at promoted level 14 → one kill).

  content with item progression replaces this scaffolding, the map +
  roster directories + registry entry get deleted wholesale (4-step
  removal documented in plan doc section 9).

  intentionally a data-load smoke test — it confirms the map can be
  loaded by the runtime, not that gameplay behaves correctly. Gameplay
  is the playtester's job; the smoke test catches silent breakage on
  unrelated refactors (e.g. someone renaming an item id).
- **`class_line_id` set explicitly on every promoted unit.** Paladin →
  `cavalier`, sniper → `archer`, bow_knight → `archer` (test choice;
  could also be `mercenary` to exercise the other line), general →
  `knight`. Required so Second Seal reclass options resolve correctly
  for the shared-promotion bow_knight case.
