## Gotchas worth remembering

- In `--headless --script` runs the project autoloads attach AFTER the test
  script's `_init`: stubs added before the first `await` claim the `/root`
  names; nodes added later are auto-renamed and lookups hit the REAL
  autoload (bit test_unit_stats' first growth-commit assertion).
- `MapCursor._show_action_menu` with a null `action_menu` falls back to
  `_commit_wait()` — headless tests exercising "menu reopens" paths must stub
  the menu or they now commit a wait RNG event (bit the first T4 attempt).
