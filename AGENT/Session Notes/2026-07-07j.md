# Session Note 2026-07-07j - B6-INPUT focus seam started

## What was done

Started the `B6-INPUT` input-mode/focus seam from the 2026-07-07i handoff.

1. **Shared selector core.** Added `scripts/ui/SelectionCursor.gd`, a pure
   `RefCounted` cursor for wrapping, inactive stops, dense grids, and sparse visual
   `(row, col)` navigation. Added `test_selection_cursor.gd`.

2. **Character-sheet Back focus gap.** `UnitDetailsScreen` now uses `SelectionCursor`
   for More Info navigation and adds a terminal Back focus zone. Moving down past the
   last content row focuses `Back`, and `confirm` closes the sheet, closing the
   deferred `V026-02e` keyboard/gamepad Back-button gap.

3. **Input-mode persistence foundation.** `SettingsManager` now persists
   `[controls].input_mode`, `[controls].touch_controls`, and relocated
   `[controls].mouse_cursor`; old `[gameplay].mouse_cursor` and
   `[gameplay].mouse_targeting` still load. `check_docs.py` now guards the
   `input_mode` and `touch_controls` vocabularies.

4. **Input-mode resolver autoload.** Added `InputModeManager` after `SettingsManager`
   in `project.godot`. It classifies live input events, ignores sub-deadzone stick
   drift, suppresses emulated mouse immediately after touch, resolves Auto/explicit
   settings through the detect floor, and emits `input_mode_changed` only on real
   active-mode changes. Added `test_input_mode_manager.gd`.

Updated DoD docs in `GDD_01`, `GDD_07`, `GDD_10`, `GDD_Feature_Index`, and the Project
Control Plane.
