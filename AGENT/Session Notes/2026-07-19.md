  `project_exchange()` sibling is required and must land first.
- `GameMap._spawn_enemy_units()` rebuilds hostiles per map via `.duplicate(true)`, so

  only. This answered one sub-decision outright.
- `ObjectiveCondition` exposes `unit_ids` and `ObjectiveConditionRegistry` is a true
  open registry, so objective criticality is a field read behind a new handler kind.
- `SkillHandler.apply_trigger()` skips any `activation_chance_stat` skill when
  `preview = true`; proc handling must become a parameter so difficulty-aware AI is
  an argument rather than a refactor.

Design amendment considered and declined: changing `[STY-8]` so counters may carry a
style. Left as written; instead `project_exchange()` must be internally symmetric
with the defender's style slot pinned null, which keeps the retrofit cheap.

Four environment/tooling defects were hit. The commits in this repo predate the fixes
and so used `--bypass-check` with the reason in the trailer; the fixes themselves
landed in the workspace container repo on `agent/from-main/check-worktree-tooling`.

1. **`scripts/check-receipt.py` could never pass for this repo.** It runs the check in
   a pristine `git worktree`, which has no `.godot` import cache because that is
   gitignored. Godot additionally clears `.godot/imported` on startup and never runs
   the import pipeline under `--headless --script`, so seeding a copy of the cache
   does not help either — that was tried and rejected. Fixed by adding a
   `--prepare-command` that runs a headless editor import pass in the worktree first.
   Verified: `agent-commit.sh` now passes with no bypass, receipt `exit_code: 0`.
2. **Switching branches invalidates the import cache**, so `run_tests.sh` reports the
   same 7 false failures until `scripts/godot-import-cache.sh` is re-run. This is
   inherent to Godot rather than a defect, but it is the same root cause as (1).
3. **`gdformat` was absent**, failing the pre-commit GDScript style gate on a
   docs-only change. Fixed by having `setup-project.sh` install a repo's own
   `requirements-dev.txt`; the image only installed the workspace-level one.
4. **`agent-start-task.sh` refused to run.** Its dirty gate counted untracked files,
   and this checkout carried untracked build output. Fixed by narrowing the gate to
   tracked changes, with untracked files reported as a warning; tracked-dirty still
   refuses, and both behaviors now have integration coverage.

The branch itself was still created with the `new_machine_transfer_checklist.md`
remedy (`git switch -f -c`) off `origin/agent/integration`, because the source
checkout also carried CRLF phantom diffs that only clear by switching branches. Those
