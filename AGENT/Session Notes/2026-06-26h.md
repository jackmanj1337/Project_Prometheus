## 1. Key reframe — scenario = reactive swap, not cover
Cover (CVR) keeps the **ally's evade** (to-hit vs ally, mitigation vs protector, no counter). The scenario
wants **full** substitution (evade + defense + skills + **counter** all the general's). Cleanest path:
**physically swap the units before resolution** via `[DSP]`, then let **normal combat resolution** run
against the tile's new occupant — full substitution is automatic, no special hook, and "general stays in
the square" is just the DSP move persisting.

## 2. The interceptor family is THREE phases (the unifying picture)
Same `[STY-9]` selector + `[REQ]`/`event` trigger + RDR-13 cost; differ only by hook timing:
- **Phase 0 — `reactive-reposition` (`[RCT]`):** target-declaration; DSP swap into the tile → full
  substitution incl. **counter**; new occupant's evade.
- **Phase 1 — `cover` (`[CVR]`):** pre-mitigation defender-swap; mitigation+HP only; ally's evade; no counter.
- **Phase 2 — `redirect` (`[RDR]`):** post-mitigation emit elsewhere.
"How much substitutes" = **which phase** you author. Phases resolve 0→1→2; each is one-hop
(non-re-reactable) to prevent loops.

## 3. The one genuine new cost (RCT-1)
Phase-0 needs a **NEW pre-resolution reaction trigger** (after target-declaration, before the exchange) —
the only break in the F11 **"no new triggers" discipline** → build-time architecture sign-off. The combat
**forecast must show the post-reaction defender** (reuse RDR-5/CVR-4 preview; AI reads same). Everything
else = `[DSP-1..17]` + `[STY-9]` + `[REQ]`/event + RDR-13 **reuse**.

## 4. Follow-ups
- **Retarget to a different (even attacker-allied) target, once:** two ways — **(a) `[RCT]` forced swap**
  (put the attacker's ally in the line of fire → it defends with its own evade and **can counter**); **(b)
  `[RDR]` full-absorb + emit at that target** (`target_filter: allies_of(source)`, `cost uses:1`) —
  delivers damage but **no dodge/counter** (it's an emit, not an exchange). Choose by whether the new
  victim should dodge/counter.
- **Can the new defender counter?** **Yes** via phase-0 swap (normal exchange, range valid since same
  tile) and the RCT forced-swap retarget; **no** via redirect emit; cover (phase-1) has no counter by
  default (murky "counter from where").

## 5. What's easy to change (parametrized)
Trigger (`[REQ]`+event: vs melee/chance/once-per-turn/HP gate) · reactor selector (`[STY-9]`) · the DSP
verb (swap/shove/pull/pivot/step) · persistence (`stay` vs `revert-after`) · cost/uses (RDR-13) · **how
much substitutes = which phase** (0/1/2).
