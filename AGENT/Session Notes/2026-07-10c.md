## What was done

- Fixed controller modal/focus regressions:
  - Settings and shared modal lists now get vertical gamepad repeat through
    `ModalScreen`.
  - `MenuRepeatPolicy.clear()` now waits for neutral input before repeating
    after a menu transition.
  - New Game focus is contained inside its modal instead of leaking to Main
    Menu controls.
  - Attack / Pair Up targeting now supports polled stick cycling.
- Fixed display readout/resize refresh:
  - `SettingsManager` listens to the root `Window.size_changed` signal as well
    as viewport resize.
  - Settings refreshes the displayed size after the settled display-size signal,
    including maximize/unmaximize paths with no resolution write-back.
- Added the MRD-7 `stacked_perimeter` candidate:
  - Generated dark-red and darker-red perimeter edge-mask overlay sprites.
  - Added overlay tileset sources 11-40.
  - Added `GridManager.SHARED_CELL_STACKED_PERIMETER` and F8 debug cycling.
  - Perimeter masks are computed from the union of retained threatened tiles.
- Tuned held trigger zoom:
  - LT/RT press threshold is now `0.35`.
  - Repeat range is now `0.45s` slow floor to `0.18s` full-pull floor.
- Updated GDD_06, GDD_07, GDD_10, and the Project Control Plane.
- Confirmed `AGENT/v0.3.0d` is already gone; returned artifacts live in
  permanent docs/evidence paths from the triage commit.
