- Owner decisions:
  - **CL-SAFETY-01** — the UI carries **two distinct signals**, not one variable "trust" badge.
    "**Data-only / can't run code**" is stated as *explanation*, because it is a **loader invariant**
    true by construction, not a per-pack check — verified in code: both pack load paths are
    `FileAccess…get_as_text()` → `JSON.parse` (`CampaignPackRegistry.gd:174`, `Tier2Catalogue.gd:195`),
    no `ResourceLoader.load()`/`load()` on pack paths, and `Tier2Catalogue` rejects `..` traversal.
    "**Valid pack — passed structure checks**" is the single **per-pack** live signal, backed by the
    existing `PackManifest.parse` + `CampaignTier2Validators`. Rejected "safe" (unbounded) and
    "unsigned" (invents a signature threat model we don't implement).
    - **Media (textures & audio) are in scope from v1.** "Data-only" is preserved by fixing the loader
      discipline now: pack binaries load **only via byte decoders** (`Image.load_from_file` →
      `ImageTexture`; `AudioStreamOggVorbis.load_from_file`; WAV from raw bytes — exact 4.6 API to
      confirm), **never** `ResourceLoader.load()` and **never** accepting
      `.tres`/`.res`/`.scn`/`.tscn`/`.gd` (a `.tres` can carry `script = ExtResource(...)` and execute
      on load). Schema gains validated texture/audio reference fields.
    - **Consequences:** enforcement test that pack content (data *and* media) never loads via
      `ResourceLoader`; batched asset loading must use the Branch I **web-safe cooperative chunked
      coroutine** (`IMPL-ASYNC-PROGRESS-CANCEL`), not threads (web is single-threaded); known
      texture-memory tradeoff (byte-loaded textures skip Godot's `.import` → no VRAM compression / no
      baked mipmaps; fine for 2D art, cap dimensions post-v1 if needed).
  - **CL-SAFETY-02** — **reject install + leave source untouched**; installed-but-corrupt shown
    **disabled** (deletion is a separate explicit action, ties CL-SAFETY-04); **quarantine deferred**;
    finer per-component status for partial corruption deferred. Advanced malformed-content forensics
    **ship with the Branch K GUI campaign editor / author validator**, not the player runtime
    (recorded against CL-ADV-02).
  - **CL-SAFETY-03** — **logical ids + safe relative paths by default; redacted otherwise; opt-in
    local full-path copy.** Concrete owner of the CL-MISSING-05 scrubber. Hard requirements: a single
    redaction helper every diagnostic + the exportable report routes through; an enforcement test that
    output never contains the user home / real absolute paths; logical ids = pack-id + pack-relative
    path (unambiguous, not absolute).
  - **CL-SAFETY-04** — **v1 = confirm + immediate hard delete**, no trash. Confirmation carries the
    safety and must be **deliberate, not mash-past-able**: destructive never default focus (CL-NAV-03);
    **proportional friction** — heavy deletes (e.g. uninstalling a pack N runs depend on, surfacing the
    CL-LIFE-06 dependency count) escalate to a **second, distinct affirmative confirmation**.
    **App-managed trash → post-v1**, explicitly **cross-platform incl. web, NOT OS-trash**
    (`OS.move_to_trash()` no-ops on web); scope = storage + retention/quota + purge + Recently-deleted
    restore UI.
