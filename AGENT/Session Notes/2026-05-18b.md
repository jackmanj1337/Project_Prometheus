## What Was Done

### 1. Full code review + documentation audit

Reviewed every production script (`scripts/**`, 38 files), `project.godot`, sample
`.tres` data, and the GDD. Two subagents assisted (UI-layer review; GDD-vs-code
divergence audit). Suite verified green throughout: **18 suites / 347 tests**.

Findings written to `AGENT/Code Reviews/code_review_2026-05-18.md`:
- **Code: 8/10.** No Critical or High correctness bugs. Mediums: `combat_animations`
  is an inert player-facing setting; `HUD` couples to `GridManager` constants;
  `InventoryEntry.validate()` is dead code (never called); `DataManager` validation
  skips the weapon/item catalogues; `NewGameScreen` changes scene even if GameState
  is null. Lows: `combat_started` emitted after RNG; `has_skill()` ignores
  `mastery_skills`; two carry-overs from the 2026-05-17 review.
- **Documentation: 4/10.** `GDD_01` had drifted heavily — wrong resource field
  names, wrong API signatures, wrong folder tree, wrong autoload list, wrong Input
  Map. Several GDD-internal contradictions and a phantom `UnitStatBlock.gd`.
