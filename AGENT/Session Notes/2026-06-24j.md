## The model
**Every combat-like action = a `source` + an optional `style`.** Source = the `[CEX-20]` weapon (incl.
spell / natural weapon / **battalion gambit**); style = a modifier layer; **plain attack = null style**.
Combat art = single-target style · gambit = AoE style · capture = non-lethal style. One pipeline:
**select source → select style → combined preview → re-derived targeting → pay combo cost → resolve.**

## Decisions `[STY-1..8]` RESOLVED (designer forks this session)
- **STY-1** unify (absorbs `[CEX-23]`; style axis is open-ended for future verbs).
- **STY-2** style = own lightweight **`StyleDef`** resource, fired via existing `player_activated` (no
  new trigger — F11 discipline).
- **STY-3** binding = `(learned/equipped styles ∩ weapon-type gate) ∪ weapon-granted` (per-weapon
  override may confer a style, optionally gated on wielder requirements).
- **STY-4** a style modifies stat-mods + range + AoE (A1); **status application rides F5** (same split
  as `[CEX-10]`).
- **STY-5** cost is **composable, NOT XOR** (user refinement): combo cost = source per-use cost **+**
  the style's `{backend, amount}` cost *set*. **Supersedes the `[CEX-6]` per-source XOR** at combo level.
- **STY-6** capture = **non-lethal style**: can't drop below 1 HP; would-be-lethal hit applies **`sleep`**
  (capture-enabling state). Damage cap → A1; `sleep` = condition → **F5**; carry/jail → **A2** (`[RCR-5]`).
  Adds a combat-capture path beside RCR talk-recruit.
- **STY-7** **full 3H battalions** scope; A1 slice = **gambit-as-style** only (AoE source, provenance
  `battalion`, charges); battalion *entity* (endurance/level/passive/assignment) → **A2** (`[STY-11]`).
- **STY-8** a style **is** the attack (costs the one combat action, not extra); battalion action-economy
  edge-cases → A2.
