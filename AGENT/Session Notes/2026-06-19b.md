## What was done

Implemented the approved immediate fix round from
`AGENT/Docs/playtest_v0.2.0_triage_plan_2026-06-19.md` in three logical commits.

were kept in sync in the same commits per DoD#1.

### `a0593c1` — Fix v0.2.0 camera zoom issues (Workstream A)

- `V020-01` High-zoom camera jitter / over-max reframe: `CameraController` now
  reduces the effective edge buffer when the visible tile span is small, and
  `step_zoom()` no-ops on already-clamped zoom indices instead of reframing.
- `V020-02` Map Zoom slider now applies live: a live-zoom application path from
  Settings to the active map's camera controller (focused on the cursor tile),
  still persisting through `SettingsManager`.
- `V020-03` Combat forecast overlapping defender under zoom: `AttackPreview` now
  treats the defender's on-screen tile rect as an avoid rect and falls back to
  above/below placement before accepting overlap.
- Tests: `test_camera_controller`, `test_attack_preview_position`, `test_map_cursor`.

### `a501277` — Fix v0.2.0 state and HUD bugs (Workstream B)

- `V020-04` F9 repeated hotseat toggle reactivating spent units: `TurnManager`
  now tracks whether the active faction's phase-start refresh already ran during a
  `start_enemy_phase()` pass and skips `_refresh_faction_units()`/`_begin_phase()`
  on same-faction F9 reruns.
- `V020-05` Seize objective zero-based coordinates: `ObjectiveCondition` renders a
  one-based player-facing coordinate while keeping evaluator/data logic zero-based.
- `V020-06` HUD reset misplacing expanded Terrain More Info: `HUD` reflows the
  expanded terrain panel relative to the compact terrain panel on reset/apply.
- Tests: `test_turn_manager`, `test_data_layer`, `test_hud_layout`.

### `0bf7b3a` — Split menu scale from HUD layout (Workstream C, `V020-16`)

- Split the global UI-scale knob: a new `Menu Scale` control scales modal/menu UI
  while HUD size/position stay owned by the HUD Layout editor (`hud_layout`).
- New `scripts/ui/MenuScale.gd` helper wired into the menu/modal screens
  (Main Menu, New Game, Settings, Map Menu, Action/Item/Weapon menus, Modal,
  Level-Up, Game Over) so menus stay centered at every supported scale.
- `SettingsManager`/`SettingsScreen`/`SettingsScreen.tscn` updated for the new
  setting; HUD no longer rides the menu scale.
- New `test_menu_scale` (centering across scales) + updates to
  `test_settings_manager`, `test_settings_screen`, `test_hud_layout`.
