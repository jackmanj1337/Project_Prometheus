## 1. Equip non-weapon items — code-grounded finding
Asked "do we have anything for temporarily equipping non-weapon items?" Findings:
- **Exists:** `InventoryEntry.entry_type=="equip"` + `is_equip()`; flat bonus fields
  `accuracy/damage/crit/dodge`; `ItemData.item_type=="equip"` (`uses=-1`). **`CombatResolver._apply_equip_item_modifiers()`
  applies these in combat** for attacker+defender. GDD_04 documents equip items (named: Full Guard, Iron
  Rune, Knight Ring, Wing Guard, Laguz Guard — all **Planned**, not built). `until_unequipped` duration
  label renders (`GameConstants`/`StatBreakdown`).

  for every equip entry held** (always-on, all stack); `until_unequipped` has **no producer** (roadmap
  forward-primitive D); the 4 combat fields can't express +STR/+MOV (would need `stat_buff`/`active_modifiers`).
- **Inconsistency:** `InventoryEntry.gd` comments those fields "M10 forging — no code reads this yet,"
  but `CombatResolver` **does** read them → reconcile when firmed.
