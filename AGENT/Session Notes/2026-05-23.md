## Decisions recorded
- Weapon identity and WEXP progression should be separate runtime concepts.
- Canonical WEXP tracks should be:
  - `sword`
  - `lance`
  - `axe`
  - `bow`
  - `tome`
  - `dark`
  - `staff`
  - `beaststone`
  - `dragonstone`
- Standard anima/light tome variants should share the `tome` WEXP track.
- Hybrid weapons should keep combat-behavior metadata separate from the WEXP
  track they train.
- Legacy runtime/content data should migrate as:
  - `fire` -> `tome`
  - `thunder` -> `tome`
  - `wind` -> `tome`
  - `light` -> `tome`
  - `dark` -> `dark`
  - `staff` -> `staff`
- `ClassData` should move toward explicit numeric class-side weapon baseline and
  cap dictionaries keyed by WEXP track.
- `UnitData` should store one authoritative numeric WEXP dictionary keyed by
  WEXP track, with rank labels derived when needed.
