## Three designer forks decided (asked this session)
- **`[CEX-22]` fallback** → **auto-fallback by priority.** When `equipped_source` is unusable (broke /
  out of charges / pool drained / `[MET]`-revoked), the engine auto-re-resolves to the highest-priority
  *usable* source and persists the swap (FE auto-equip-next). Priority = usable-now sources, inventory
  slot order then granted order, with a universal infinite **fists** floor; nothing usable + no floor →
  counter with nothing. Single-source (no range-aware pick — that's `[CEX-23]`).
- **`[CEX-23]` combo-select rework** → **reserve schema, defer the build.** Source+maneuver selection,
  combined preview, re-derived targeting are the end-shape but NOT built now; v1 stays single-source
  (equip → Attack → target). Reserve only `equipped_source` + an optional maneuver/art id note for F1.
  Lands with combat arts (#15) / gambits (#16). Largest fork in the cluster — deferring keeps F1 moving.
- **`[CEX-7]` loadout** → **ever-growing known list v1, cap later** (reuse `[SKL-3] requires_equip` for
  the cap + forget/swap when it lands).
