# Session Note 2026-07-07b - B6-INPUT headless cursor pass

## What was done

Finished the headless-safe **`B6-INPUT` controller map-cursor pass** on
`v0.3.0-features`.

- Widened `MapCursorInput` from key-only decoding to `decode(event)` so d-pad and
  pad buttons use the same intent path as keyboard input.
- Added polled left-stick cursor movement through `Input.get_vector()` using the
  existing tile-repeat timer:
  - immediate first step;
  - 0.25s delay;
  - 0.10s repeat cadence;
  - dominant-axis handling for diagonals;
  - clear on deadzone/neutral.
- Added held zoom polling through `Input.get_action_strength()` so LT/RT can
  repeat discrete zoom steps, with stronger trigger input repeating faster.
- Guarded keyboard zoom echo so held keyboard zoom does not double-step through
  both OS key repeat and the new polling path.
- Added `AGENT/Docs/playtests/playtest_checklist_v0.3.0.md` for the live-only
  controller checks: real mapping, stick deadzone/repeat feel, trigger feel,
  menu focus comfort, mixed-input behavior, and visual overlap.
- Updated GDD/control-plane/gamepad-plan docs and regenerated the docs index.

Tests added/updated:

- `test_map_cursor_input.gd` now covers d-pad/pad-button decode, d-pad release,
  polled vector repeat, and dominant-axis handling.
- `test_map_cursor.gd` now covers live cursor movement from d-pad + polled stick,
  held zoom repeat, trigger-strength cadence, and keyboard-echo suppression.
