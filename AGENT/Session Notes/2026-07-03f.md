baked authoring**. Questions:
- `[PUG-1]` UnitSpec + roll mode (explicit ranges vs class-growth-rolled → rec **both**).

- `[PUG-3]` **the spawn seam** — generalize `enemy_placements`/`_spawn_units` to accept an
  in-memory `UnitData`, not only a path (load-bearing; unblocks every consumer).
- `[PUG-4]` `ForceSpec` resource (roster + counts + scaling).
- `[PUG-5]` `EncounterDef` `{ForceSpec, map_source, reward}` as the overworld-ready atom

- `[PUG-7]` auto/random-level scaling via `[DIF]`/`[TCV]` (open registry of scaling terms).
- `[PUG-8]` editor **generate-and-bake** (same primitive; the editor persists/freezes the
  roll; re-roll before save) — runtime-generated vs authoring-generated distinction.
- `[PUG-9]` equipment gen (fixed vs table → both).
- `[PUG-10]` consumer map — one generator + `ForceSpec` + spawn seam back arena, recruits,
  skirmish, editor, reinforcements (`[DTR-5]`), property-recruitment, PvP.
