## 1. The substrate finding (the spine of the pass)
Action-grant = the **`is_self:false`, full-turn, activated** branch of the **same**
`grant_extra_turn(unit, {can_move, can_act, is_self})` call that `[SMV]` uses for Secondary Movement.
SMV = passive/self/move-only; Reinvigorate = activated/ally/full-turn. So almost the whole SMV register
transposes — **no bespoke engine subsystem.** Code-grounded: the action economy is just
`TurnManager.UnitState {READY, MOVED, DONE}`; `can_unit_act` already accepts READY|MOVED, and
`_refresh_faction_units` already re-`READY`s a faction each phase — **a refresh is "set a DONE/MOVED ally
back to READY,"** a transition the engine already performs. Reinvigorate/grant_extra_turn are **unbuilt**
(grep clean), confirming greenfield-over-described-substrate.

## 2. `[AGT-1..12]` highlights
- **AGT-1** activated, parameterized `SkillData` (`effect_id="grant_action"`, `is_player_activated`);
  reuses the skill stack wholesale (mirror `[SMV-1]`).
- **AGT-2** scope = `effect_params.grant_mode ∈ {full(default), move_only, act_only}` → the substrate
  flags. **Default `full`** (Dancer canon) — owner call.
- **AGT-3** activated targeted skill: legal target via `[STY-16]` filter + `[STY-17]` relationship gate
  (allies/non-hostile), range a param (default adjacent), **valid target = `state != READY`** (must have
  already acted — settles the note's "re-grant an already-acted unit" edge), `[STY-10]` preview, no RNG.
- **AGT-4** conferral = existing skill-grant paths (mirror `[SMV-4]`); Dancer/Bard class default unlock.
- **AGT-5** Dance **is** the caster's turn-ending action (dancer→DONE) ⇒ net "spend one to refresh one";
  composes with the caster's own SMV (dance-then-reposition).
- **AGT-6** refresh = `grant_extra_turn` re-READYs the target, which re-enters the active controller
  (M14 stage 5); atomic, grants exactly the authored scope.
- **AGT-7 (owner call) — anti-loop = author TOOLS, not a baked rule.** Two general tunables: (1) a net-new
  transient `Unit.actions_taken_this_turn` counter + an author **refresh cap** (cap 1 = the balanced
  default; a capped unit is an invalid grant target), cleared in `_refresh_faction_units`; (2) a
  **generic per-source per-phase/round/map action-rate-limit** — broader than action-grant (→ forward-pin).
  The A↔B infinite loop is closed by setting *either*. No hardcoded "danced-can't-dance."
- **AGT-8** F10 interaction = fully composable, zero special case.
- **AGT-9 (owner call)** off-turn = **on-turn only v1**; reserve a per-source `off_turn_grant` flag
  (default off), inheriting `[DSP-12]` non-interrupt when built.
- **AGT-10** AI queries the same capability; heuristic at AI build (mirror `[SMV-10]`).
- **AGT-11** save: skill grant persists; the transient counters need **no field unless mid-phase save is
  in scope** → flagged for the F1 lock.
- **AGT-12** all tunables = `CampaignRules` defaults overridable per source/skill (mirror `[DSP-17]`).
