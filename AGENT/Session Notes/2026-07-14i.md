- **`B1-CST` Slice 3 is Implemented — the Load Game picker landed, and the
  roadmap row flipped from Split to Implemented (DoD#1).** All three spine slices
  are now Implemented: a campaign runs end to end and survives a quit.
  - `LoadGameScreen` is a MainMenu overlay on the established `ModalScreen`
    pattern (`open()`/hide, cancel-to-close, `MenuScale` group) — the same shape as
    `NewGameScreen`/`SettingsScreen`, so Back cannot lose the menu.
  - **The picker does not restore a save.** Activating a row emits
    `slot_load_requested`; MainMenu runs its existing `_load_campaign_slot`. That
    was the load-bearing design call: Continue and Load Game now share ONE restore
    path (GameState staging -> `CampaignManager.launch_current_node()`, plus the
    failure dialog), so they cannot drift apart — and the eventual reroute to prep
    (`B4-PREP-DEPLOYMENT`) stays a one-line change in one place.
  - Rows render entirely from `SaveManager.list_slots()`, whose index rows mirror
    each save's header at write time, so **drawing the list never opens or
    validates N save files.** Rows arrive newest-first by the monotonic `write_seq`
    and are deliberately **not** re-sorted — `saved_at_unix` is whole-second
    resolution and two saves in the same second would tie.
  - The autosave is **listed, not hidden, but marked `[Autosave]`**: it is the one
    row that gets overwritten under the player, so it must not read as a save they
    wrote themselves.
  - Delete sits next to Load on every row, so it confirms first. `delete_slot`
    already clears the Continue pointer when it named that slot; the picker then
    emits `slots_changed` so MainMenu redraws — Continue falls back to a surviving
    slot, or disables when the last one goes.
  - Load Game is disabled while `list_slots()` is empty, mirroring Continue: a
    player with no campaign save sees exactly the old menu.
- **Manual save is deliberately still absent** (reassigned 2026-07-14): writing a
  slot is a BETWEEN-map action and belongs to the prep screen.
  `CampaignManager.write_campaign_slot` is built and tested and waits for
  `B4-PREP-DEPLOYMENT`. Mid-map saving is already the suspend save's job.
- Contract updated: `GDD_07_Screens_Panels.md` gained a §Load Game Screen section
  and its Main Menu section now describes the two-document Continue.
