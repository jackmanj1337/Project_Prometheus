## Decision — override-reaching strategy (AskUserQuestion)
The signed-off D2 assumed "scale one root Theme → children reflow," but a root Theme does
**not** reach per-node `theme_override_font_sizes` (GameOver title=48, LevelUp 20/16/14/12,
headers). Real fork surfaced:
- **(A) runtime-derived Theme + walk/scale the overrides** — scenes stay intact, factor 1
  byte-identical, forward-compatible with a future base theme. **Chosen.**
- (B) author a base Theme + strip overrides from all ~11 scenes — the from-scratch ideal,
  but a big scene rewrite + full project-wide visual re-verify.
User deflected ("which would you choose from scratch?"). Answer: **B from scratch, A for
this codebase** — B's only advantage is "no overrides to migrate," which we'd have to
*build*; A reaches the same crisp result without touching the scenes and doesn't foreclose
B later (an authored base theme can seed the runtime-derived one).
