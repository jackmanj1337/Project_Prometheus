## 2. The reframe (owner, 2026-06-23)
**SELF-CONTAINED, everything user-defined.** Each campaign is a **complete, independent** bundle of
content; **no runtime inheritance/overlay** — `select_campaign(c)` *replaces* the content dicts with c's
full set. Default content ships with the **builder** as a copy-from palette and is **copied
`res://`→`user://` on first run**; the loader then uniformly enumerates `user://` campaign dirs; all
content art is **raw-loaded** (`Image.load_from_file`→`ImageTexture`). **Costs the owner explicitly
accepted:** duplication/bloat + **no central patch propagation** (fix a default → re-ship each campaign).
**Benefit:** trivial runtime (no merge engine / version coupling), maximally portable packs.

## 3. Resolutions `[ICO-1..6]`
- **[ICO-1] = SELF-CONTAINED** (neither overlay option). Reverses 2026-06-23a.
- **[ICO-2] = A (whole-resource)** — trivial; campaigns store full resources, no merge.
- **[ICO-3] = provenance only** — the explicit add/override tag the owner first picked loses its runtime
  validation role (no base to validate against); kept as authoring-time `forked_from` for the builder +
  a future resync tool. Per-campaign duplicate-id stays a hard error. (Owner accepted this downgrade.)
- **[ICO-4] = provenance stamp only** — `builder_content_version`, informational, no load gate.
- **[ICO-5] = copy to `user://` on first run** — everything user-defined; uniform enumeration; raw-image
  art. **New build scope:** first-run seed-copy + reset/repair path (the heaviest piece).
- **[ICO-6] = A** — `icon: String` on `WeaponData`+`ItemData` + `resolve_icon()` raw-Image; field+seam
  now, **UI rendering deferred**. Reinforced by ICO-5 (a `Texture2D` export can't reference `user://` art).

## 4. Consequence — `[DMR-4]` merge → replace-load
Self-contained collapses the merge: `select_campaign()` does `_clear_content()` + `_load_all(campaign.dir)`
+ `_validate_all()`. The DMR-4 **seam stands** (`_load_all(source)` + `select_campaign()` entry); the
`_apply_overlay()` **merge body is retired**. Net: runtime is *simpler* than the overlay design; the real
new engine work moved to ICO-5 (seed-copy / `user://` enumeration / raw art / repair).
