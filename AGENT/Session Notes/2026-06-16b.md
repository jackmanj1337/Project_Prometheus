### 1. Code review of the 2026-06-16 feedback slice (`514f0fa`)
Reviewed the branch diff as the session note directed. Overall solid (headless-safe
guards, EventBus decoupling, matching tests + DoD#1 docs). Three findings, all low
severity, all fixed in `653a31f`:

- **F9 guard refund** (`TurnManager.start_enemy_phase`) — the enemy-phase cycle guard
  (`turn_order.size()+1`) was consumed by F9 re-runs that replay the *same* faction, so
  rapid mid-phase F9 toggling could trip the spurious "never returned to blue" abort.
  Re-run `continue` paths now refund the decrement. Added a regression test
  (`test_turn_manager` 62 → 63) that ping-pongs the override past the raw guard budget.
- **Null hotseat controller** (`_controller_for`) — documented that F9-with-no-hotseat
  intentionally skips the faction (debug-only; real maps always register one).
- **PU badge position** (`Unit._refresh_pair_up_badge`) — horizontal offsets now derive
  from `GameConstants.TILE_SIZE` instead of hardcoded 64px-sprite offsets.
