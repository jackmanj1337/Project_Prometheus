## 2. The taxonomy reframe (owner asked for the full target list)
The key insight that shaped everything: most "AI profiles" collapse onto **two orthogonal axes +
one modifier**, so the taxonomy is small and composable, not a long flat enum:
- **Axis 1 — engagement disposition:** basic✅, passive✅, `guard_tile`, `territorial`, `patrol`,
  `flee`, (+ fast-follow `retreat_when_low`, `kite`).
- **Axis 2 — special role/action:** healer✅, (gated) `buffer`, `thief_steal`, `fog_scout`,
  `chest_looter`, `siege_operator`, `dancer`.
- **Modifier `target_policy`** (a placement key, NOT a profile): `nearest` (default), `weakest`
  (focus-fire), (fast-follow) `hunt:<unit_id>`.
- **`boss` is not a profile** — `is_boss` flag composes onto a disposition.

Full table with buckets + data/gate per profile = register §2a (canonical roadmap).
