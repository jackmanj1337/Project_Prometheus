### Orphaned-process cleanup + root cause
Five hung `godot --headless --script` processes (3× `test_pair_up_bonus_e2e`, 2×
`test_stat_contributions`) had been alive for hours. Killed them (PID 1 session
shell + the analyzer MCP server left alone).
- **Root cause:** a `SceneTree`-based test only exits when `_init()` reaches its
  explicit `quit()`; headless `--script` has no idle auto-quit. My buggy early
  drafts errored mid-`_init()` (the `%q` format error; a typed-array `[]`
  assignment) **before** `quit()`, so godot idled forever. The Bash tool then
  backgrounded each; the fixed re-runs exited (~8s), but the original hung copies
  were never reaped → orphans.
- Saved memory `feedback_godot_headless_test_quit` so this carries forward.

### Test-runner timeout guard (commit `84800ee`)
`run_tests.sh` wrapped no `timeout` around per-suite godot, so a test that errors
before `quit()` (or genuinely hangs) would stall the whole suite — and
pre-commit/CI — indefinitely. `run_one()` now uses
`timeout --kill-after=10 $TEST_TIMEOUT` (default 180s, generous vs ~8s real
runtime); a 124 exit is reported `TIMED OUT` and counts as a failure. CI inherits
it via `run_headless_tests.sh → run_tests.sh`. Full suite still green.
