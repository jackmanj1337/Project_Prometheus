## 2. The model (firmed)
`redirect` = an **effect interceptor**: on a matching incoming effect it **(a)** optionally **absorbs** a
portion off the holder (pre-application) and **(b)** emits a **transformed effect at a `[STY-9]`-selected
target-set** (post-application). "Reflect" = preset `target={source}`; **full absorb + bounce** = the
parry/full-reflect fantasy. **Deterministic spine:** intercept → predicate → resolve target-set
(`N_intended`/`N_valid`) → compute absorb+redirected → gate absorb (RDR-11) → holder takes
`incoming−absorb` → emit to valid targets (non-redirectable) → death snapshot-resolve.

## 4. Sibling `cover` (`[CVR-1..6]`, OPEN)
Pre-application **reassignment** (mirror of redirect): moves the **original** effect's target to a
protector before it lands — protector's own mitigation vs the original attacker, **original**
kill-attribution = FE Aegis/guardian "take the hit *instead of*". Distinct from `redirect.absorb=1`
(which emits a new holder-attributed effect). Shares the interceptor family, `[STY-9]` selector,
`CombatResolver` hook, M8/A5 deps. **To walk next.**
