## 3. The one substantive refinement — determinism is per-OUTPUT-PATH (amends EXT-4)
Confirming across three vocabularies sharpened EXT-4 from "fixed-point for determinism" to a per-path rule:
- **(1) decision/predicate** (REQ · MET guards · `chance`) → **pure + fixed-point + Package-A RNG**.
- **(2) state-mutation** (MET actions) → **deterministic, ordered** engine primitives at safe points, RNG
  via Package A.
- **(3) presentation** (DLG visual render) → **determinism-EXEMPT** (never feeds save/replay); only the
  *gating* (`loop_until<cond>`, branch conditions) rides deterministic REQ.
- Consequence: an F4 profile feeding the `chance` odds inherits fixed-point (crosses into class 1); a DLG
  cosmetic does not (no pointless fixed-point cost on visuals). **Flagged to the owner as the only new
  design content; not objected to.**
