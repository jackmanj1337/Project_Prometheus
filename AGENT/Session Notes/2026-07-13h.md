## Findings that block the release gate

- **F1 (Medium)** — the missing-`DeathLifecycle` fallback in `CombatResolver` is
  circular: it delegates to `Unit.handle_death()`, which is itself a delegate to
  the same autoload and no-ops when it is absent. With the autoload missing, a
  unit at 0 HP is never unregistered, never emits `unit_died`, and is never freed.
- **F2 (Medium)** — `_spawn_units()` now returns false on any single placement
  failure and `_ready()` aborts, leaving a half-built map where v0.3.x loaded.
  `GridManager.get_terrain_at()` returns `"wall"` as a sentinel for an unpainted
  cell, a tileset missing `terrain_type`, or an out-of-bounds tile — so a content
  slip now kills the whole map, and DataManager cannot see it (it validates
  `map_data.grid`, not the TileMapLayer the runtime reads).
- **F3 (Medium)** — the mutual-death invariant has no coverage.
  `simultaneous_group_id` and `responsible_actor` appear in zero test files;
  `test_combat` asserts only result flags computed before the death block. This is
  why F1 shipped unnoticed.

## Decisions taken

- **D1/F2** — map-start placement moves to `nearest_free`, then skips the unit if
  no tile is free. A placement problem must never abort a map. `push_warning` on
  displacement keeps tileset slips visible; DataManager validation stays strict
  and gains the missing enemy-tile bounds check.
- **D2/F1** — delete the fallback, `push_error` instead. A second death
  implementation would re-open the seam the slice closed.
- **D3/L2** — keep the projection runtime guard cheap (RNG + `party_gold`); prove
  unit-state preservation in a test; correct the contract wording.
- **D4/L5** — close the registry boundary (`reload_presets(source)`, strict
  replace) so "self-contained source" is true; document the suspend-path occupancy
  bypass as intentional. Flagged as the one item that adds capability rather than
  removing risk, and the first to cut if the RC diff must stay corrective.
- **D5/L6** — delete `is_registered_id()`. It is an instance method while every
  DataManager validator is `static`, so it cannot serve the purpose its docstring
  claims.
