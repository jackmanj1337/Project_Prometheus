# Session Notes — 2026-05-21f

## Focus
Class & skill system rebuild to support the Awakening-style class descriptions
in `AGENT/GDD/Content Expansion/awakening_classes_and_skills.md`.

## What was done
Planned and implemented milestones M1–M5 of the rebuild, then wrote a full
handoff plan for M6. Docs:
- `AGENT/Docs/class_skill_rebuild_plan_2026-05-21.md` — overall plan + M1–M5 status.
- `AGENT/Docs/m6_promotion_plan_2026-05-21.md` — detailed M6 (promotion) handoff plan.

- **M1 — Schema.** `ClassData` now splits growths into `player_growth_rates` /
  `enemy_growth_rates`, adds `stat_caps`, `skill_unlocks` (level→skill id),
  `tier`; `promotion_stat_increases` renamed to `promotion_stat_bonuses`;
  `starting_skills`/`promotion_skill`/`occult_skill` removed. `UnitData` gains a
  personal `growth_rates`. `DataManager` validates the new fields. All 6 class
  `.tres` migrated.
- **M2 — Level-up engine.** `Unit.level_up` picks the growth table by team
  (enemy table for non-blue, player table + personal growths for blue), clamps
  gains to `stat_caps`, and auto-learns `skill_unlocks` skills at their level.
  `unit_leveled_up` signal now carries learned skill ids.
- **M3 — Level-up UI.** `LevelUpScreen` shows a "Learned <Skill>!" line.
- **M4 — Skill resources.** 11 FE:A base-class skills created as `.tres` from
  the wiki. Effect logic deferred to the existing M9 milestone (registered as
  stubs in `SkillHandler`).
- **M5 — Class & roster data.** 5 classes rewritten with doc FE:A values;
  `cavalier.tres` added; `unit_01` swapped from Soldier to Cavalier; all 6
  roster units given personal `growth_rates`.

- **M6 — Promotion.** Not implemented; fully planned for handoff in
  `m6_promotion_plan_2026-05-21.md`. Covers schema, promotion flow, the
  auto-promote campaign rule, promotion items, the 15 promoted-class data
  tables, ~28 new skill resources, a 7-commit breakdown (M6.1–M6.7), tests,
  and a Second Seal / reclassing effort estimate (~30–40% on top of M6).

All 24 test suites green after each milestone; working tree clean.
