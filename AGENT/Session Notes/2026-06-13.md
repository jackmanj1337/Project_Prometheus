# Session Notes - 2026-06-13

## Focus

Audit whether the v0.1.4 playtester handbook is fully usable by a tester who
has never read the GDD or source code, then correct the gaps found.

## What was done

- Added standalone Windows requirements, executable size, SHA-256, and an
  optional PowerShell verification command.
- Added tester metadata fields, result rules, screenshot guidance, crash
  recovery, and `NOT RUN` handling.
- Added a complete controls table, basic gameplay flow, unit-identification
  instructions, F10 behavior, and a glossary of mechanics and abbreviations.
- Added exact displayed coordinates for Seize, Escape, and Defend tiles.
- Added the missing Map 003 Defeat Boss and Map 005 Defend objective checks.
- Added Windows `godot.log` collection instructions so testers do not need a
  visible debug console.
- Corrected Pair Up flows that incorrectly attempted movement or combat on the
  same phase that Pair Up spent both units' actions.
- Reordered Map 002 so the occupied Seize tile is tested after the boss and
  other Red units are defeated.
- Replaced the impossible level-9 `M950_Knight` Second Seal test. Tier-1 units
  cannot reclass below level 10, and the fixed Map 950 tier-1 units have no
  reclass options configured. The handbook now uses the valid
  `M950_General -> Soldier` demotion path.
- Replaced the incorrect Map 950 "one Blue death causes Game Over" instruction.
  Map 950 uses allied Rout defeat, so the handbook now tests Retry from the
  Victory screen, which exercises the same map-start snapshot.
- Made level-dependent Map 950 checks deterministic with the F10 Force Level
  Up aid.
- Left unrelated untracked screenshots and June 12 GDD drafts unchanged.
