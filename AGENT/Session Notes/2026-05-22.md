## What was done
- Read the latest prior session note before starting.
- Audited the existing local/container test flow and confirmed the key CI risk:
  a fresh clone needs Godot's import/class-cache bootstrap before the headless
  GDScript suites can run.
- Standardized the default Dockerfile Godot version to `4.6` so the Dockerfile,
  `docker-compose.yml`, and the new CI workflow all target the same version.
- Added `scripts/ci/run_headless_tests.sh`, a CI-style wrapper that:
  - runs `godot --headless --path . --import --quit-after 1000`
  - verifies `.godot/global_script_class_cache.cfg` exists
  - runs `bash run_tests.sh`
- Added `.github/workflows/tests.yml`:
  - checks out the repo
  - installs Linux runtime dependencies
  - downloads Godot `4.6` headless from the official GitHub release
  - runs `bash scripts/ci/run_headless_tests.sh`
- Updated `README.md` with:
  - the new CI-style local wrapper command
  - a short GitHub Actions section and the required post-push verification step
- Validated the wrapper locally end to end; it passed the full suite after the
  fresh-clone import/bootstrap phase.
