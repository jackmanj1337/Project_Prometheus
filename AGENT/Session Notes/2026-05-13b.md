### Godot Analyzer MCP Server (tools/godot-analyzer-mcp/)
Built a pure-Python stdlib-only MCP server that Claude Code loads on startup. Provides 5 static-analysis tools for Godot 4 project files:
- `get_scene_nodes` — full node table from a .tscn with types and script paths
- `find_scenes_with_script` — reverse-lookup which .tscn files attach a given script
- `get_resource_fields` — exported field values from a .tres resource
- `validate_onready_paths` — checks every `@onready $path` in a .gd file against the scene that uses it; reports OK/MISS per line
- `get_autoloads` — lists all autoloads from project.godot

Registered via `/workspace/.mcp.json` — Claude Code picks it up after restart.
