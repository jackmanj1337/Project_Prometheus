## Key unification
Avatar units and author-defined story protagonists are the **same structure** — a `UnitData` with an
elevated **narrative-identity role, orthogonal to class**. They differ only by a **provenance** flag:
author-fixed (protagonist) vs player-authored (Avatar). No bespoke avatar system; Avatar reuses the
role + the relationship plumbing. "Not based on a certain class" = identity is a **unit property**,
not a Lord class — a main character may start any class, reclass freely, and keep the role.

## Decisions `[MCH-1..8]`
- **Role bundle** (defaults-on, each overridable): must-survive · relationship hub (REL-8 slot) ·
  dialogue name-substitution · **forced deployment** (overridable per-character AND per-map).
- **Must-survive** = role auto-adds a campaign-wide `protect`/defeat default (reuses the existing
  `ObjectiveCondition` `protect` type — already in code), author overrides per-map. Game-over even in
  casual/phoenix unless overridden (confirm in A5).
- **Class decoupling** = identity on the unit, not a class; unique classes optional, never required.
- **Avatar player-authored fields** = author opts the player in **per field**: name · portrait
  (pick-from-set OR format-constrained file upload, rides the campaign-pack raw-load art pipeline) ·
  starting class (author-allowed set) · stat growths · special skill(s).
- **Name/text indirection** = story/UI text references units by **`unit_id`**, resolved to display
  name at render; **templated with named placeholders, never concatenated** → foundation **F13**.
- **F1 schema** reserves: role + bundle toggles, provenance, avatar player-authored fields.

## New foundation F13 — text indirection / localization-ready string layer
Researched how games localize (string externalization, Godot native `tr()`/`TranslationServer` +
CSV/PO, **templates-with-placeholders never concatenation**, plural/gender forward surfaces, avatar
**free-text-name** grammar edge). **Decision: adopt the convention NOW, defer the multi-locale
build** — the `unit_id`-pointer move IS the i18n foundation; doing it right from the first authored
line is near-free, retrofitting is expensive. Resolution would use Godot's native translation;
per-campaign-pack string tables (fits the self-contained content model). **Enforcement (DoD#2)
explicitly deferred:** the `check_docs` linter lands when the dialogue/story-text data format is built
(no target data to lint yet) — a deliberate deferral, not a skip.
