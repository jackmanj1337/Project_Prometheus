## Key findings that shaped the drafts
- **`rebind_action` is destructive** (`keybindings[action] = [event]` overwrites the whole
  list) → the moment the gamepad plan adds joypad events, a keyboard rebind would wipe them.
  Hence [ICD-4] (per-device slots) and the rebind plan drafted around it.
- **`emulate_mouse_from_touch`** means a tap emits *both* a touch and a mouse event → the
  resolver's detection needs an explicit touch-vs-emulated rule ([ICD-3]); also load-bearing
  for the web build's V021-17 tap path.
- **The `ui_*` mirror + baseline already solves** the "old key stuck on ui_accept" edge — the
  rebind UI reuses it, doesn't re-implement it; conflict detection checks *game* actions only.
