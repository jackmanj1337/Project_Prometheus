## 1. The model — `redirect` = an effect INTERCEPTOR (not damage-only "reflect")
`redirect` subscribes to incoming **effect-application events** on its holder; for events matching a
`[REQ]` predicate it emits a **transformed effect at a selected target-set**. "Reflect" (bounce at the
dealer) is the **preset** `target = {source}` — so the general primitive is "on-intercept → transform →
emit at a target-set," authored once and composed as data (the closed `[EXT]` "one model = A" pattern).
Determinism **class-2** (state-mutation: deterministic, ordered, safe-point, fixed-point, PkgA RNG).

## 2. Owner end-shape calls (AskUserQuestion, 2026-06-26)
- **Subject = damage · conditions · other combat effects** (general, not damage-only).
- **Carrier = any source** — one effect, GRANTED by a status condition / equipped item / class trait
  (the granted-source pattern, as battalions use). No bespoke carrier.
- **`fires_on_death` = a per-effect author flag**, engine default = dying-thorns.
- Then: **"reflect to people matching a criteria"** → promote `target` from the constant `source` to a
  **target-selector** (`anchor` + spatial `scope` + `[REQ]` predicate). Owner named the primitive
  **`redirect`**.

## 3. Three new engine rules (recommended defaults, in `[RDR]`)
- **Read point** = post-mitigation **actual** value; emitted effect applied **through the target's own
  pipeline** (target defenses + `[REQ-15]` floor apply). Avoids double-mitigation.
- **Termination** = emitted effects flagged **non-redirectable → one bounce only** (kills thorns-vs-thorns
  and radiate cascades; non-negotiable).
- **Death ordering** = lethal blow defers disposition to a safe point → `redirect` fires per
  `fires_on_death` → all flagged deaths resolve in **A5's** order. `redirect` is a **co-input to the A5
  death/removal-disposition decision** — the reason it is walked pre-A5.

## 4. The real cost — foundation dependencies NOT in current code (verified against the repo)
- `ConditionManager.gd` is a **37-line no-op stub until M8** — conditions have no apply path yet.
- Damage flows through `Unit.take_damage(amount)` (Unit.gd:446): applies an **already-mitigated** number,
  emits `unit_damaged(self, amount)` **with no source**. `CombatResolver` is the only place that knows
  attacker→defender + owns death timing.
- ⇒ General `redirect` requires the **M8** build to expose **(a)** a uniform **source-bearing**
  `effect_applied(kind, magnitude, source, target)` event, and **(b)** a **shared unit-selector**
  (anchor+scope+predicate) — the **same** selector the spell/style AoE system needs (build once, both
  consume). Hook belongs in **`CombatResolver`**, not `take_damage`. Spatial pieces already exist
  (`GridManager._tiles_in_range` + `_get_units()`), so the selector is composition, not new math.
