## What was done
Owner walk through the five remaining open questions. **Keystone reconciliation:** PUG's
sketched `EncounterDef {ForceSpec, map_source, reward}` **collapses into CNC-4's
`BattleEncounterDef`** — a skirmish encounter is just a `BattleEncounterDef` whose force and
map are generated/pooled instead of authored. One encounter concept, not two.

- **`[PUG-4]` ForceSpec → A (first-class resource).**
  `{entries:[{UnitSpec,count}], level_scaling, count_scaling}`. Rolls each entry via
  `generate_unit(spec,seed)`, produces in-memory `UnitData` placed through the `[PUG-3]`
  seam. Arena ladder = degenerate 1-entry ForceSpec; skirmish = full one.
- **`[PUG-5]` EncounterDef → unify into `BattleEncounterDef`.** No separate wrapper. The
  encounter gains authored-OR-generated modes: force = authored `enemy_placements` XOR
  generated `force_spec`; map = fixed `battle_map_id` XOR `map_pool` (pick/rotate). Reward
  reuses the existing `reward_gold`/`reward_items` fields. A trigger surface (skirmish panel
  now, overworld tile later) fires the same launch path via `[CNC-8]/[CNC-9]`.
- **`[PUG-6]` skirmish container → A (PHB prep panel).** `map_source` = the encounter's
  `map_pool`. **Schema refinement fed back into CNC-4:** `BattleMapDef` gains
  **`enemy_start_tiles`** (enemy spawn zones symmetric with `player_start_tiles`) so a
  generated force can be placed on any map in a pool; also serves reinforcements (`[DTR-5]`).
- **`[PUG-7]` scaling → open registry of scaling terms** over `[DIF]`/`[TCV]`, default =
  player-average level + difficulty offset. Bases (player-avg/max, chapter index, fixed
  band, TCV var) are data terms, not a hardcoded `match`. Author-selectable per ForceSpec.
- **`[PUG-8]` editor bake → A.** Editor calls the same `generate_unit`, shows an editable
  result, **freezes** the roll to a concrete pack `UnitData` on save. One primitive, two
  persistence policies (runtime re-rolls/discards; editor freezes). Named-character
  freeze-provenance stays a §6 forward reservation.

Updated §4 slice sketch (now RESOLVED, ready to promote to a build track) and the CNC-4
`BattleMapDef`/`BattleEncounterDef` schema entries with the PUG refinements.
