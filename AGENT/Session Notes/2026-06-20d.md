Key decisions/recommendations captured:

  controls outside the game visuals.
- Add a `Project Prometheus Web Debug` export preset targeting `builds/web-debug/index.html`.
- Use a single-threaded Web export with PWA disabled for the first pass.
- Route HTML touch controls through a Godot-side `WebInputBridge.gd`, not synthetic
  keyboard events.
- Default new Web debug settings to `mouse_cursor = "click"`.
- Host the first playtest as an unlisted/passworded itch.io HTML5 page unless the user
  chooses another host.
- Treat this as a debug Web playtest channel, not full mobile support.
