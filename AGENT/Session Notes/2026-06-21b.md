## Resolved scope (A–J)
- **A — spine:** MVP spine first; **linear now but overworld-ready** (model "next map" as a
  progression-**graph node**, not a hardcoded chain, so a later Awakening-style overworld with
  chapters/interludes/wandering encounters/side-quests drops on top); between-map **prep surface**.
- **B — save model:** in-app slots **+ filesystem export/import**; **persistent re-loadable**
  suspend; **reloading always free** (permadeath = deaths stick only if you don't reload);
  **multi-choice Game Over** menu (reload recent / reload any / main menu / hidden charge-gated
  Rewind); Continue = **resume-most-recent**; auto + manual save; slot menu shows
  chapter/playtime/party/ruleset-badges/editable label.
- **C — prep:** always between maps; deploy/bench with per-map **required + excluded + cap**,
  player-assigned placement onto map-authored tiles; benched gain nothing; **MVP prep = deploy
  + save + launch only**.
- **D convoy / E shop / F recruit / H Pair-Up-persistence / Support / Rescue:** **all DEFERRED**
  from this cluster (save schema reserves `party_items`/`party_gold` + full-roster persistence
  so they're later data-growth, not reshapes).
- **G — rules:** player-**locked**, **story-flippable** (scripted mutation seam, explicit
  in-game flip notification), read-only prep view, **tinkerer warning** in the save's rules region.
- **I — homebrew:** **portable saves now, packs later.** Human-readable JSON + `format_version`
  + `_warning` fields + editable `save_label` + **integrity hash**; load = **tamper-aware
  warn-and-continue** (NOT hard reject) with a secondary warning on author-marked protected
  fields. **Export = single `.json` now**; importer **sniffs `PK\x03\x04` vs `{`** so a future
  zip campaign-pack imports with zero migration (Godot 4.6 `ZIPPacker`/`ZIPReader` make standard
  interoperable zips trivial when needed). Web caveat: FS export/import on web routes through the
  browser download/upload sandbox.
- **J — rewind:** **hooks now, mechanic later.** Reuses `rng_determinism_design_2026-06-11.md`:
  per-committed-action Turnwheel (RNG-1), per-map charge pool on `CampaignRules` (RNG-3, default
  3–5, `0 = ironman`), snapshot carries `{map_seed, history_hash}` (RNG-2). This cluster adds the
  rule + charge persistence + defeat-menu entry; the mechanic is **hard-blocked on `RngService`
  (Package A)**.
- **I5 (added at user request):** **cross-version save transfer is NOT a concern until 1.0** —
  keep `format_version` as cheap insurance, but write no migration code pre-1.0; compat may break
  freely between versions.
