**Started:** 2026-06-29. Draft tracker created from
[`gdd10_active_work_coverage_matrix_2026-06-29.md`](gdd10_active_work_coverage_matrix_2026-06-29.md).

rewrite should link to. `GDD_10` becomes the readable build guide; this document
owns the audit rows.

The row schema, Track ID uniqueness, Track ID reachability, allowed Track ID
prefixes, allowed statuses, allowed bands, and local markdown links are enforced by
[`check_docs.py`](../check_docs.py).

## Row Schema

Every tracker row uses these columns:

| Field | Meaning |
|---|---|
| Track ID | Stable id referenced by `GDD_10` and the feature index. |
| Band | Dependency band or non-feature queue. |
| Status | Governance label only: Planned, Target design, Pending validation, Deferred, Open decision, Known issue, Historical, Superseded, Implemented. |
| Work item | Human-readable name. |
| Scope | One-sentence build or audit scope. |
| Blocks / depends on | Track IDs or named prerequisites. |
| GDD owner | Numbered GDD owner chapters. |
| Decision source | Register, design doc, plan, or decision source. |
| Build source | Implementation plan, build guide, or `needs plan`. |
| Save / registry impact | F1 rows, save guard, registry family, or `no_save_guard`. |
| Test / validation | Automated, manual, doc-check, or release validation. |
| Next action | The next concrete step. |
