## Remaining work — Workstream 6 (Map HUD / Camera / Input)

All deferred from this session because they require visual verification
which is not possible from a headless environment. Each item lists
file ownership, what the expected behavior is, and the trap.

### W6a — Map details show one-based coordinates

- **Owner:** `scripts/ui/HUD.gd`, `scripts/core/MapCursor.gd` (cursor tile
  display)
- **Change:** wherever the HUD prints `tile.x` / `tile.y`, show `+1` so
  the upper-left tile reads `(1, 1)`. Internal storage stays zero-based.
- **Trap:** do NOT change tile_position storage anywhere; only the display.
  Adding `+1` at the print site is the entire fix. Test by inspecting a
  player_start_tile that is `Vector2i(0, 0)` in map data — HUD must show
  `(1, 1)`.

### W6b — Compact-to-expanded terrain details grow upward + scroll

- **Owner:** `scripts/ui/HUD.gd` (terrain details panel), the HUD scene's
  terrain panel anchor.
- **Change:** anchor the panel to the bottom edge. On expand (the F-key),
  add a ScrollContainer so excess content scrolls instead of clipping.
- **Trap:** the compact mode currently grows downward (which clips the
  available-actions strip). Keep the compact form's footprint at the
  bottom; only the expanded form needs the ScrollContainer.

### W6c — Camera viewport-aware overscan for edge panels

- **Owner:** `scripts/core/CameraController.gd`
- **Change:** the camera limits should include extra space equal to the
  HUD's right/bottom panel width/height so the cursor can pan the camera
  far enough that the bottom-right map tiles are visible above the HUD.
- **Trap:** overscan must be viewport-aware — at 1280×720 the bottom
  panel takes more proportional space than at 1920×1080. Read the panel
  rect and feed it into the camera's limits at viewport resize time.

### W6d — Slower/smoother mouse-follow camera catch-up

- **Owner:** `scripts/core/CameraController.gd` mouse-follow code +
  `SettingsManager` if the user pref exists.
- **Change:** lower the catch-up lerp constant. Investigate whether
  `SettingsManager` already exposes a `camera_smoothing` or `pan_speed`
  pref; if not, ship a sensible default rather than adding a new pref
  this slice.
- **Trap:** the playtester comment in `GDD_Manual_Tasks.md:256` asks for
  a pref + overscan combo; per the locked decision in
  `playtest_fix_plan_2026-06-09.md:28-29`, overscan is fixed and only
  pan speed is the pref. Don't add a new overscan toggle.

### W6e — Mouse-wheel over New Game UI does not move map camera

- **Owner:** `scripts/ui/NewGameScreen.gd` (mouse_filter / GUI input
  handling) + `scripts/core/CameraController.gd` (zoom input gate)
- **Change:** the New Game panel's outer Control needs `mouse_filter =
  STOP` so wheel events do not propagate to the camera. Verify the
  camera reads zoom from `_unhandled_input`, not `_input`.
- **Trap:** the title screen camera state currently persists into the
  Main Menu UI session; even with mouse_filter fixed, double-check that
  Main Menu UI does not invoke `CameraController.handle_input` directly.

### W6f — Movement Cancel returns cursor to selected unit

- **Owner:** `scripts/core/MapCursor.gd` `_undo_move_and_reselect` /
  `_on_targeting_cancelled`
- **Change:** the Cancel path while a unit's movement preview is active
  must `_set_tile(selected_unit.tile_position)` before returning to
  `UNIT_SELECTED` state.
- **Trap:** `test_map_cursor.gd` line ~388-407 already covers
  `_on_targeting_cancelled` returning the cursor to the acting unit;
  ensure the *movement* cancel (not targeting cancel) does the same.

### W6g — Map-menu backdrop and Cancel dismissal restore control

- **Owner:** `scripts/ui/MapMenu.gd` (likely a missing backdrop
  ColorRect + `gui_input` handler)
- **Change:** add a transparent ColorRect at the bottom of MapMenu that
  catches clicks and emits `menu_closed`. Wire Cancel keypress to the
  same path.
- **Trap:** confirm `_on_map_menu_closed` in `MapCursor.gd:99`
  unfreezes the cursor. Backdrop click must route through that same
  signal, not a separate close path.

### W6h — Per-enemy threat inspect

- **Owner:** `scripts/core/MapCursor.gd` + the threat overlay code in
  `GridManager.gd` / `HUD.gd`
- **Change:** when the cursor is on an enemy tile in FREE state, holding
  a modifier (or `inspect_unit` action) shows that enemy's threat only.
  `Q` continues to globally toggle all enemy threat.
- **Trap:** don't break the existing `Q` toggle. Add a per-tile mode
  that overrides the global display while active, then reverts to
  whatever global state was set.

### W6i — Center New Game panel beneath its title

- **Owner:** `scenes/ui/NewGameScreen.tscn`
- **Change:** anchor the options panel so it horizontally centers under
  the title, regardless of viewport width.
- **Trap:** the title sits at a fixed offset already; the panel needs
  anchor_left = 0.5 + matching offset_left/right.
