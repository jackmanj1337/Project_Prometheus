# What this session closes — the display-gated task list

Every row below has been sitting open for the same reason: nobody in a container can
look at a screen, hold a controller, or install to a phone home screen. This is what
the session is buying. Each row names the evidence that closes it; anything short of
that evidence leaves the row open.

Tracker ids are from `coordination/tasks.json` in the container repo.

| `IMPL-TERRAIN-VARIANTS-AND-PACK-TERRAIN-2026-08-01` | tile sizing and atlas regions; whether variants of one terrain read as the same terrain | the terrain-variants decision in `DECISION_SHEET.md` |
