## The one worth more than its own line

`IMPL-FILEDIALOG-ESCAPE-TEXTINPUT-2026-07-29` claims `SettingsManager.gd`,
`SettingsScreen.gd` and `SettingsScreen.tscn`. Closing it releases a claim that **three
other pieces of work are queued behind**:

- the Settings screen conversion to the size-class model;
- Menu Mode and information density becoming persisted settings (`ResponsiveLayout`
  holds them in memory today precisely because that file is claimed);
- dropping `system` from the text-entry vocabulary (`TEXT-V1-S06`, currently blocked);
- and flipping the retired 1280×720 constant in
  `SettingsManager.fit_content_scale_factor_for_size`, which is the direct cause of
  2.7 CSS px body text in phone portrait.

That is why §4 of the checklist is the section this whole round exists for.
