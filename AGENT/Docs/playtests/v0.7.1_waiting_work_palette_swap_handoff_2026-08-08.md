## Goal

Add one non-compositional palette swap for each `(faction, visual_state)` pair. A valid
swap replaces faction tint and done-darkening. Any absent, unsupported, invalid, or
unavailable swap follows one unconditional tint fallback and records structured repair
evidence. The HP bar remains faction-coloured in every case.

## Contract to implement

1. Register `palette_swap@1` as its own catalogue kind. It is pack-level and addressable
   by id so several sprite sheets can share it. Use the existing open schema registry;
   do not add a closed type switch.
2. Represent mappings as an ordered list of full 8-bit RGBA `from`/`to` colours. First
   duplicate input wins and produces a warning. Transparent source pixels are handled
   specially; fully transparent outputs are refused. Runtime matching is exact.
3. Enforce one named maximum of 32 mappings. Keep 16 as an authoring warning, not a
   runtime error. The same maximum must drive validation and shader capacity.
4. Give each swap its `(faction_id, state)` binding and tint fallback. Start with
   `state = normal|done`; keep faction ids open because maps author them.
5. Let each sprite asset explicitly list supported swap ids. Resolve every reference
   within the one active pack. Never union with engine defaults or another pack.
6. Adapt validated swaps and supported ids into the active content session. Do not load
   raw catalogue JSON from `Unit` and do not infer ids from filenames.

If an existing schema surface cannot express an item above without creating a second
authority, stop and amend this handoff rather than hiding the gap in `Unit.gd`.

## Rendering structure

- Put shader/material construction in a small pure helper, not inline in `Unit`.
- Use one exact-match colour-remap `canvas_item` shader compatible with
  `gl_compatibility`. A swap is evaluated against native art once; never layer faction
  and done swaps.
- Preserve CanvasItem modulation in the shader (`COLOR`, `MODULATE`, and texture sample
  composition). This is a known trap: a shader that writes only the sampled colour can
  silently discard fallback tint and done-darkening.
- `Unit` asks for `(team, normal)` initially and `(team, done)` when spent. When lookup
  or shader application fails, use the swap's tint fallback; if no record exists, retain
  today's faction tint and `DONE_APPEARANCE_DARKEN` behavior.
- Keep `_hp_bar` faction-coloured. Palette art is authorable; the HP bar is the stable
  non-authorable faction cue.
- Return structured repair entries for every degradation. Missing swap data is never a
  fatal pack error.

## Required automated evidence

- Schema: valid swap, 32 accepted, 33 refused, duplicate-input warning, transparent
  output refused, unknown supported-swap id refused, open faction id accepted, closed
  state vocabulary enforced.
- Pure helper: exact RGBA mapping, partial mapping leaves unmatched colours alone,
  first duplicate wins, and material uniforms have deterministic ordering.
- Unit: normal and done choose separate keyed swaps; no layering occurs; missing swap
  uses faction tint; missing done swap uses darkened fallback; reset restores normal;
  HP-bar colour is unchanged by every sprite swap outcome.
- Tier-2 activation: a real fixture carries a shared pack-level swap through validation,
  adaptation, DataManager activation, and Unit lookup.
- Run focused suites, shader parse under Godot 4.6.3, scene integrity, GDScript style,
  then `bash run_tests.sh`.
