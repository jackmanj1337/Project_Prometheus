# Decisions to make from the images

Each entry names the image that shows it and offers concrete options. "Does this look
right?" is not a question anyone can answer twice the same way, so none are phrased
that way. Write your answer under each one.

Images live in `screenshot-album/` (this build) and `screenshot-album-reference/`
(v0.6.1, for comparison). Filenames encode the case:
`<surface>__<width>x<height>__menu-<scale>__content-<scale>__safe-<t-r-b-l>.png`.

**Read this first — what the album diff already tells us.** Every one of the 133 cases
resolves the *same* menu scale, content scale and safe-area insets as v0.6.1: the
filenames are identical between the two albums. But 126 of the 133 captures differ as
images. So the framing maths did not move; what moved is what is drawn inside the
frame. That is the change you are being asked to judge.
