## Important limit

The runtime consumer accepts an asset record shaped as
`{path, decoded_type, sidecar_path}`. The current Tier-2 adapter still emits only
`{path, decoded_type}` because the catalogue/schema/archive contract for admitting the
JSON sidecar is not yet defined. Do not add a filename convention or silently infer
`<image>.json`; `[CSA-4]` requires catalogued art and an explicit sidecar reference.

The next implementation slice is therefore the narrow catalogue boundary:

1. settle and validate the `art_asset@1`/sidecar reference shape;
2. admit only referenced sidecar JSON through archive preflight;
3. carry its resolved absolute `sidecar_path` through
   `CampaignTier2RuntimeAdapter.assets`; and
4. extend the runtime-adapter fixture so a real activated pack drives the resolver.

Keep that work separately tracked because it touches pack validation and archive security.
