## v0.2.2 — ordered task list

> Order = play-blocking → tester-visible UI → designed systems. Each item: goal · key files
> · acceptance/test · docs. Full detail in the triage plan.

### 1. V021-01 — Hotseat per-selection rollback
- **Goal:** F9 toggles never revive units that took a turn-ending action; a unit that is
  mid-move or selected-but-not-finalized **rolls back to its pre-selection tile/state and
  stays READY**; AI-moved (turn-ended) units dim before phase end.
- **Files:** `MapCursor.gd` (`_original_tiles`, `_undo_move_and_reselect`), `TurnManager.gd`,
  `HotseatController.gd`, `EnemyAI.gd`; `test_turn_manager.gd`, `test_enemy_ai.gd`,
  `test_map_cursor.gd`.
- **Accept:** headless — (a) AI unit that finished its action stays DONE across F9 toggles;
  (b) a unit selected/moved but not turn-ended is restored to its original tile and READY on
  handoff; (c) an in-flight AI tween cancels and restores on toggle.
- **Docs:** GDD_01 §Turn / Activation (+ GDD_10 M15 hotseat notes) + GDD_10 V021-01.

### 2. V021-02 / 03 / 04 — HUD layout editor
- **Goal:** (02) editor is modal — leaving Settings exits the editor; cursor/menus don't
  leak; reset reflow holds under stress. (03) sample text stays in-bounds, editor-only.
  (04) terrain corner stays snapped on resize; clamp size/offset on-screen.
- **Files:** `HudLayoutEditor.gd`, `HUD.gd`, `SettingsScreen.gd`; `test_hud_layout.gd`,
  `test_hud_layout_editor.gd`.
- **Accept:** reflow derives expanded-panel offset from the active page size (also hardens
  the V020-06 reset bug); resize-then-snap regression test; sample-text-bounds test.
- **Docs:** GDD_07 §HUD Layout + GDD_10 V021-02/03/04.
