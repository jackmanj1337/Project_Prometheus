## Behaviour changes to eyeball in live play (headless-tested only)

- **V021-01 mid-tween cancel is end-state only.** On an F9 toggle *during* an AI
  move animation, the unit finishes the tween then snaps back to its start tile
  (logical state is correct: start tile + READY). No tween handle is retained, so
  there is a brief animate-then-snap-back. Verify it isn't jarring; if it is,
  retain the tween on the unit and kill it on handoff for a clean cancel.
- **V021-02 modal capture** swallows *all* non-mouse input while the editor is
  open. Confirm with a real keyboard/controller that nothing else (cursor, menus,
  other Settings) responds, and that `cancel` closes the editor (not Settings).
- **V021-06 selector axes** — verify Up/Down/Left/Right on a d-pad match the
  on-screen grid across class/stat/skill/wexp rows, including the all-inline
  skills row and the wrap at top/bottom.
- **V021-09 wording** — the sheet now shows Pair Up as "until separated" and
  always-on stat skills as "—" (permanent, was "this combat"). Confirm that
  reads correctly to a player.
- **V021-17 click cursor mode** — headless tests cover disabled/follow/click hover gating,
  first-click move, second-click select, and terrain-panel page cycling. Live-verify with
  a mouse/touchpad that `click` mode feels deliberate, that terrain panel clicks do not
  accidentally select map tiles, and that `follow`/`disabled` still match their labels.
