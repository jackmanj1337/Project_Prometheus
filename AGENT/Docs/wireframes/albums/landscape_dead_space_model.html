The controls live in the dead space, and so does the keyboard

Owner ruling: landscape reserves, and grip width is not a number anyone authors — it is whatever the chosen game view leaves over. That single rule replaces the reservation question, and it is what makes a split keyboard possible.

Decided — 2026-08-06 Landscape reserves. The game view is placed at the size and shape the player picks; the leftover letterbox is the control region. Separation holds in both directions by construction rather than by rule.

The keyboard splits in half so the main screen stays visible: left keys in the left dead column, right keys in the right one, game view untouched between them.

Earlier the same day: the layered 7-column keyboard, the field echo strip, and removing the system setting.

The rule Place the game view at the player's chosen size and aspect. Whatever is left over is the control region. During a text-entry session the keyboard occupies that same region — wherever it happens to be. One rule; portrait and landscape are two outcomes of it, not two designs.

Which makes the current landscape default the actual bug

ControllerLayout._default_viewport() returns {x:0.05, y:0.03, w:0.90, h:0.55} for portrait — a chosen rectangle with real leftover — but {x:0, y:0, w:1.0, h:1.0} for landscape. A full-bleed rectangle leaves zero dead space, so under this rule there is nowhere for controls to go and the presets named Side Grips and Bottom Dock can only be overlays.

Note the difference from an emulator: those get their letterbox for free, because they are showing a fixed-aspect device on a phone. Prometheus has aspect=expand and will happily fill the screen, so it has to choose a rectangle deliberately in order to have any dead space at all. Portrait already does. Landscape is the half that was never set.

A–M left thumb · N–Z right thumb · 6 rows of 44px keys = 284px in 393 · game view never moves

Each thumb owns its own half and never crosses the screen — which is how the hands are already resting, and the reason a split keyboard beats a wide one on a device this size. The layers decided this morning do the work here too: 123 and #+= live on the left pad, so the split costs no characters.

The echo strip is redundant in this shape and should stay a Compact device. It exists because a Compact keyboard covers the band and the field can scroll out of a four-row list. Here the field is on screen, in place, the whole time — which is the entire point of splitting.

The catchThe split is only as wide as the player's choice

Dead space being derived is what makes the model clean, and also what makes it conditional. A 44px key needs 48px of column, so the number of columns per side is a direct function of the aspect the player picked.

4:3 is the boundary. At 3:2 and wider the columns cannot hold three 44px keys, and a split keyboard stops being possible — which matters, because a tactical map is exactly the kind of view a player would widen.

The honest options when the dead space is too narrow, in the order I would rank them: shrink the game view for the duration of the session (a text session is already modal, and it keeps both separation rules true); fall back to a single block in the larger dead region; or let the keyboard overlay the view, which breaks the rule that just made all of this coherent.

What this leaves open

  1. The narrow-dead-space fallback. The one real question left. My recommendation is temporarily re-fitting the game view — it is the only option that keeps strict separation true at every aspect, and modality already justifies it.
  2. Does the landscape default rectangle get a value, or a preset list? Portrait ships one default (0.55 height). Landscape needs at least one that is not full bleed. 4:3 is the widest that keeps the split keyboard, which is an argument for making it the default rather than a choice.
  3. Split point. A–M / N–Z is drawn above because it is the obvious cut. Frequency-balancing the halves would put fewer common letters on the weaker thumb, and is worth a look only if the even cut tests badly.
