Distribution Surface — Proof Set

S5/S6 · drawn 2026-08-15 · logical pixels · ResponsiveLayout.DENSITY_TOKENS · unpainted (UUI-16)

One skeleton — holder · pool · detail — rendered for eight consumers at four viewports, to test whether convoy, loadout, skills, styles, battalions, shop, forge and on-map Trade are one surface with adapters or several surfaces that merely rhyme.

The hypothesis under test. LDC-1 already rules one mechanism for every cap-bound category (earned superset → equipped subset → cap). RPD-11 rules Manage Roster an open registry of panels. EPUX-24 rules one atomic quote/commit core with shop and forge as thin panels over it. BAT-10 and CNV-8 both delegate presentation to "the existing equip/loadout affordances", which have never been drawn. If those rulings are right, one skeleton should serve all eight. These frames are where that either holds or visibly fails.

Status: hypotheses. Nothing here is an accepted UI contract. Frames drawn against a ruling carry the id in a solid chip; frames drawn against a recommendation or an open proposal carry a dashed chip. Measurements are read from the rendered layout, not estimated.
