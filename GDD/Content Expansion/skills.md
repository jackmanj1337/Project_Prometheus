# Fire Emblem TTRPG — Skills

> Skills can be assigned or removed at any time out of combat, or at any other time the GM sees fit.  
> Maximum skills per unit: **4** (expandable at GM discretion).  
> Skills marked with **\*** are activated by choice.

---

## Class-Specific Skills

These skills are tied to specific classes and are granted at start or at a certain level.

| Skill | Effect | Class |
|-------|--------|-------|
| Pick\* | Opens doors or chests without needing a key | Thief line — from start |
| Canto\* | 1 adjacent ally without the Canto skill that has already acted can move and act again this turn | Bard line, Heron — from start |
| Reverberate | Canto targets all adjacent allies when in animal form | Heron — from start |
| Feral Instincts\* | Shift forms at will; shifted stats only get 25% boost instead of 50%; shifted MOV −1; while shifted, EXP gain is halved | Cat, Tiger, Hawk, Raven |
| Wildheart | +5 Starting shift gauge (can have this skill multiple times) | Cat, Tiger, Hawk, Heron, Raven |
| Primal Tenacity | Shift gauge starts each map where the shift gauge was at the end of the last map | Cat, Tiger, Hawk, Heron, Raven |
| Untamed Persistence | +2 shift modifier per turn in humanoid form (can have this skill multiple times) | Cat, Tiger, Hawk, Heron, Raven |
